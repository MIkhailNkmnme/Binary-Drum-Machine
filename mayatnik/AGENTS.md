# Правила проекта «Маятник»

## Текст кнопок

- В видимых надписях кнопок исключать гласные, если они находятся между двумя согласными внутри слова.
- Русские гласные: а, е, ё, и, о, у, ы, э, ю, я. Буквы ь и ъ не считать согласными.
- Определять соседние буквы по исходному слову; сохранять регистр и остальные символы.
- После сокращения добавлять «ъ» в конец каждого слова, которое заканчивается на согласную. Слова на «ь» или «ъ» оставлять без дополнительного знака; после гласной «ъ» не добавлять.
- Примеры: «Ширина» → «Шрна», «Центр» → «Цнтръ», «Цвет» → «Цвтъ», «Заливка» → «Злвка», «Ось» → «Ось».
- В подсказках и доступных названиях оставлять полный понятный текст. Не сокращать идентификаторы, значения настроек, имена файлов и пользовательские данные.
