# Версии

Правило: **каждая правка движка поднимает его версию.** Крупная — целое число
(33 → 34), обычная — десятую (34.0 → 34.1). Версия проставляется в трёх местах
`Zerkalius-code.html`: шапка комментария, `<title>` и заголовок `<h3>` в панели.
В `Zerkalius-genezis.html` — в подписи рядом с названием (`v0.420`).

## Общие модули

Три вещи вынесены в отдельные файлы и подключаются одной строкой — правка
чинит сразу все машины:

| файл | что делает |
|---|---|
| `recorder.js` | запись видео с холста, кнопка ⏺ и клавиша R, хранилище кусков и восстановление оборванной записи |
| `hub-link.js` | значок ⌂ «в Хаб», путь считается сам, клавиша H |
| `slider-arrows.js` | стрелки ◂ ▸ у каждого ползунка, удержание повторяет |

`slider-arrows.js` следит за появлением новых ползунков: в машинах, где панели
собираются во время работы, стрелки достаются и им.

## Остальные машины

Ко всем машинам с холстом подключён общий модуль записи `recorder.js` — кнопка
⏺ в правом нижнем углу, горячая клавиша R.

Запись не живёт в памяти вкладки: куски ложатся в IndexedDB по ходу дела.
Делить их между памятью и диском нельзя: заголовок файла приезжает одним из
первых кусков, и собранное без него видео не открывает ни один проигрыватель.
Поэтому до подтверждения готовности хранилища куски ждут в памяти и уходят
на диск все разом, начиная с нулевого.
Закрытие вкладки во время записи браузер переспрашивает, а если её всё же
оборвали — при следующем открытии страница сама предлагает сохранить
недописанное. Теряется только хвост, не дошедший до диска (секунды две).
Имя файла переводится в латиницу: кириллицу в `download` у blob-ссылок Chrome
молча отбрасывает, и запись падала безымянным файлом без расширения.

Про частоту кусков: шаг `start(1000)` соблюдает только webm — он отдаёт ровно
по куску в секунду. Mp4-муксер Chrome копит кадры у себя и отдаёт примерно раз
в три секунды, а на `requestData()` отвечает пустыми кусками. Столько и
потеряется, если вкладку всё-таки оборвут.

Прежние версии движков лежат в `versions/` — по файлу на версию, целиком
и работоспособные: их можно открыть в браузере и сравнить с текущей.

| файл | что это |
|---|---|
| `versions/Zerkalius-code-33.0.html` | кодовая машина до этой сессии |
| `versions/Zerkalius-code-34.6.html` | до ускорения радара |
| `versions/Zerkalius-code-34.7.html` | до записи видео на диск |
| `versions/Zerkalius-code-34.8.html` | до склейки перерисовок при прокрутке |
| `versions/Zerkalius-code-34.9.html` | до починки заголовка в записанном видео |
| `versions/Zerkalius-code-35.0.html` | до починки звука и частоты кадров |
| `versions/Zerkalius-genezis-0.420.html` | флагман до этой сессии |
| `versions/Zerkalius-genezis-0.424.html` | до ускорения радара |

| `versions/grid-module-8.html` | Grid Module до записи видео |

Номер поднимается только там, где он обозначает версию страницы — в `<title>`
и в видимой подписи. Упоминания версий в комментариях («появилось в v1.511»)
не трогаются: это история, а не ярлык.

Порядок при правке движка: сначала копия текущего файла уходит в `versions/`
под своим номером, потом поднимается версия и вносится правка.

## Обновление на втором компьютере

`update.bat` тянет свежее с GitHub, `cleanup.bat` сжимает хранилище git,
`git-v-papku.bat` переносит каталог истории внутрь рабочей папки, если тот
вынесен наружу (рядом с файлами тогда лежит не папка `.git`, а файл `.git`
с путём внутри) — после переноса проект переезжает на другой диск одной папкой.
Если переносить нечего, он показывает раскладку: где рабочая папка, где
история, откуда тянется обновление и не берутся ли объекты из чужого
хранилища.

`update.bat` сначала копирует себя во временную папку и работает уже оттуда.
Иначе он ломается на собственном обновлении: `cmd` читает `.bat` прямо с диска
по ходу выполнения, запоминая смещение в байтах, а `git pull` заменяет этот же
файл — и `cmd` продолжает читать новый со старого места, посреди строки. В
таком обрыве `git` превращается в `it`, и следом выполняется случайный кусок.

`versiya.bat` показывает, что за версия лежит в папке и на сколько правок
она отстала от GitHub. Ничего не меняет, только смотрит.

Все батники с русским текстом лежат в кодировке **CP866**: `cmd` читает их
не в UTF-8, и русские строки иначе выходят кракозябрами. Типографские тире и
кавычки в них не годятся — в CP866 их нет.
Уборка вынесена отдельной кнопкой не просто так: git изредка затевает её сам
посреди обновления, и если файл держит антивирус или индексатор Windows,
останавливается на вопросе «Deletion of directory failed. Try again?».
Обновление в один клик не должно ничего спрашивать, поэтому `update.bat`
запускает `git pull` с `gc.auto=0`.

Локальная папка `_Versions1/` остаётся в `.gitignore` — она не уезжает на
GitHub, поэтому архив лежит рядом с проектом и виден всем копиям.
