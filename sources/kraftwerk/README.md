# Источники · Kraftwerk

Два изображения предоставлены пользователем и сохранены без изменения файла.

- `3d-the-catalogue-cover.png` — обложка300×300 из первого сообщения.
- `3d-der-katalog-palettes.png` — обложка и восемь цветовых вариантов2032×1347 из сообщения05.11.2026.

Визуальный источник: Kraftwerk — 3-D The Catalogue / 3-D Der Katalog. [Контекст альбома](https://en.wikipedia.org/wiki/3-D_The_Catalogue). Это не собственные оригинальные иллюстрации проекта. Цветовые пресеты — приближённая реконструкция по предоставленному изображению, не официальные коды цветов Kraftwerk.

Каталог `catalog.json` добавляет настоящие файлы в Битотеку при её открытии, в раздел «Источники», коллекцияKraftwerk. Удалённые пользователем локальные записи не восстанавливаются автоматически; проектные исходники остаются доступны по прямым ссылкам.
