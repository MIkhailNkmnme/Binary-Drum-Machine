# Источники проекта

`catalog.json` — общий каталог Битотеки: изображенияKraftwerk и карточки научных источников. Импортируются при открытии Битотеки; это локальная копия записей в браузере, а сами исходники хранятся в проекте.

- `kraftwerk/` — предоставленные пользователем обложки.
- `perception/collin-2006-spatial-frequency/` — короткая русская карточка статьи PMID16491707, ссылки, смысл и связь с битглифами. Полный текст статьи не скопирован; описание по аннотации.
