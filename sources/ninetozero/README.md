# NINETOZERO · визуальная коллекция

Галерея v0.004 (18.11.2026): [изображения и кадры NINETOZERO](https://1001100.online/sources/ninetozero/).

По решению пользователя сейчас сохраняются только изображения:

- `frames/`: 40 сохранённых кадров; имя файла и подпись содержат ID исходного видео. Названия произведений оставлены для атрибуции изображений.
- `images/`: 49 уникальных файлов официального сайта: обложки, афиши и фотографии. `assets.json` сохраняет исходные URL изображений, страницы обнаружения, размеры файлов и SHA-256. Сбор изображений выполнен 16.11.2026; новая сетевая загрузка не выполнялась.
- `8nxGxtRnqFQ/comment.png`: предоставленный пользователем скриншот комментария @valentin3386. `reference.json` содержит только происхождение изображения.
- `releases.json`: названия десяти визуальных источников и официальные страницы их происхождения.
- `scripts/collect_images.py`: сбор только изображений; Python, requests и beautifulsoup4. Сборщик аудиопревью удалён.

Аудиофайлы, сопровождающие их TXT, музыкальные описания, текст комментария и его перевод удалены. На странице нет музыкальных плееров и ссылок для прослушивания. Изображения принадлежат соответствующим правообладателям и не объявляются собственными работами Зеркалиуса. Собственная музыка и звук проекта создаются с нуля; эта коллекция служит только визуальным источником.

Проверки интерфейса и визуальная приёмка остаются пользователю. В этом изменении выполнены чтение и правки исходников; тесты, браузер и прослушивание не запускались.
