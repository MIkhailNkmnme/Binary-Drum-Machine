# NINETOZERO · исследование

Статья v0.003 (17.11.2026): [кадры из видео NINETOZERO](https://1001100.online/sources/ninetozero/). В `frames/` сохранены кадры в исходном размере. Имя файла — ID ролика YouTube. Сравнивались до девяти кадров в каждом из 44 роликов. Interconnection включён с коротким затемнением в конце. Сбор от 16.11.2026 доступен в Битотеке:

- `images/`: 49 уникальных файлов, найденных на 26 публичных страницах официального сайта. Исходные URL, страницы, размеры и SHA-256 находятся в `assets.json`.
- `audio/`: 33 публичных превью Apple Music (30–90 секунд), полученных по LISTEN-ссылкам лейбла. FFprobe подтвердил аудиопотоки и измерил фактическую длительность. Это не полные треки. Рядом с каждым файлом — TXT с описанием релиза и ссылками.
- `releases.json`: 10 релизов, исполнители, композиции, даты, краткие русские пересказы описаний и ссылки на площадки. `trackDuration` относится к полной композиции, `local_audio.duration_seconds` — к сохранённому превью.
- `texts.txt`: все описания в одном текстовом файле. Это не тексты песен.
- `8nxGxtRnqFQ/`: скриншот комментария @valentin3386, его текст и сведения об источнике. Изображение предоставлено пользователем, переносы строк нормализованы. Текст не сверялся с аудио и не объявлен официальными lyrics/переводом.
- Полная загрузка YouTube остановлена ответом «Sign in to confirm you are not a bot». Авторизация и обход проверки не выполнялись.
- В HTML официального сайта не обнаружены прямые полные аудиофайлы. Внешний Bandcamp отвечает Client Challenge; магазины и социальные площадки не архивировались.
- `scripts/`: сбор изображений и загрузка превью. Python + requests + beautifulsoup4, для аудио также ffprobe в PATH или FFMPEG_PROBE. Скрипты повторяют сбор в этой папке.

Происхождение файлов сохранено. Изображения и аудио принадлежат соответствующим правообладателям. Проверки интерфейса оставлены пользователю по правилам проекта; проверка файлов не означает визуальную приёмку.
