# Рендеры

Кадры и клипы, снятые скриптами из `tools/`. Всё воспроизводится заново:
поднять `npx http-server -p 8080 -s .` в корне и запустить нужный скрипт.

- `CONTACT-SHEET.png` — контактный лист: 20 рецептов узоров одним листом
- `clips/` — клипы 1280×720, 24 fps, 5 сек, H.264

Клипы здесь пережаты (CRF 28) — это превью для быстрого просмотра с телефона.
Мастера под монтаж генерируются заново из `tools/clips.js` (CRF 18) и в
репозиторий не кладутся, чтобы он не разбухал.

| клип | рецепт |
|---|---|
| `r04-Воронка` | Серпинский «Центр» + режим Воронка |
| `r07-Радар_воронка` | радар + воронка, шаг поворота 7 |
| `r15-Рентген` | заполнение пустот `x` + конгломераты |
| `r16-CRT_терминал` | XorRora, VT323, кровавый пресет |
| `g03-GPU_радар_воронка` | то же на ⚡ WebGL (Pixi) |
| `h01-Хоррор_Красный_тотем` | кровавый пресет + шлейф + свечение, скроллинг |
| `h02-Хоррор_Призрак` | ч/б, рентген + скрытие неменяющихся символов |

Кадрирование: движок считает центр по раскладке с панелями, а скрипт панели
прячет, поэтому сверху может оставаться чёрная полоса. Перед финальным
монтажом кегль и число строк подгоняются под 16:9.

## Готовые ролики

- `merlin-720p.mp4`, `merlin-540p.mp4` — 6:44 под «Waiting For Merlin» Lee Van Dowski (126 BPM)
- `vsnares-1080p.mp4` — 1:37 под Venetian Snares, шаг по реальным ударам
- `laniakea-720p-preview.mp4` — 8:03, 12 сцен под «Laniakea» (100 BPM)
- `laniakea-540p.mp4` — та же сборка, сжатая для телефона

Мастер 1080p (141 МБ) в репозиторий не кладётся — он больше лимита GitHub.
Пересобирается за пару минут из готовых сцен:

```
bash tools/scenes.sh                      # сцены, если их ещё нет
bash tools/assemble.sh трек.mp3 renders/laniakea-1080p.mp4
```
