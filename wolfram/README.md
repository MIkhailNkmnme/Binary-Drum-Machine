# Зеркалиус · Вольфрам v0.002

Отдельная конусная лаборатория и две статьи: [страница](https://1001100.online/wolfram/), [Маятник](https://1001100.online/wolfram/mayatnik.html), [Аниматрица](https://1001100.online/wolfram/animatrix.html).

## Назначение и границы

Эта страница соединяет наш порядок конусных проходов с таблицами элементарных двоичных правил 0–255. Она не подменяет существующий Маятник и не является обычной временной диаграммой одномерного автомата. Один шаг — полный проход конуса. Старое приложение и его сохранения не изменяются. Звука нет.

- Базовый режим 90 + накопление + чтение по ходу напрямую вызывает `MAYATNIK.cone` из `../mayatnik/mayatnik-core.js`.
- В общем случае `f(L,C,R)` берёт три клетки верхнего ряда. Накопление отдельно добавляет старый бит целевой клетки через XOR. Номер 150 не равен исходному тройному XOR Маятника.
- Режим «Снимок» фиксирует входы после временной установки вершины в 1; режим «По ходу» читает общее изменяемое поле.
- Маска конуса проходит через одну клетку; вне неё значения сохраняются. Пустота и внешняя граница дают входной 0, но записанный 0 отличается от пустоты в данных.
- Маршруты: 0,−1,+1,…; зеркальный; влево; вправо; повтор одной вершины. Глубина 8–256, проходы 1–512, ширина не более 1022.
- Настройки хранятся в `zerk_wolfram_cone_lab_v1`; поле и состояние воспроизведения не сохраняются. При открытии выполнение остановлено.

## Файлы

`engine.js` — вычисления и нормализация параметров; `app.js` — управление, сохранение, canvas; `index.html`/`style.css` — интерфейс. `mayatnik.md` и `animatrix.md` — исходники статей, `animatrix-evidence.json` — карта статусов утверждений и источников. `build-articles.py` форматирует Markdown в статический HTML (Python + пакет Markdown), не запускает симуляции. Иллюстрации Аниматрицы взяты из существующего `../issledovanie/`.

## Происхождение

Математические правила реализованы самостоятельно поверх собственного ядра проекта. Исходники Mathematica/CDF Вольфрама не копировались и не переводились в JavaScript. Архив программы книги использован для чтения и сопоставления. Указание автора само по себе не разрешает публикацию изменённых версий его исходников: [условия книги](https://www.wolframscience.com/nks/piv--copyright/), [официальные программы](https://www.wolframscience.com/nks/programs/).

Бинарная волна Аниматрицы точно соответствует оператору префиксной суммы mod 2 из примечания NKS, с. 931. Этот вывод не охватывает смешанные метки, Excel-режимы и Маятник. Полного точного аналога связки базового Маятника в просмотренной книге и программах не установлено; это не доказательство новизны. [Протокол поиска](../issledovanie/wolfram-nks/xor-pendulum-comparison.md), [метаданные охвата](../issledovanie/wolfram-nks/source-search/scope.json).
