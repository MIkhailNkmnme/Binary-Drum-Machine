Зеркалиус · Вольфрам v0.001

Наш Маятник хранит двумерное поле и снова проходит по нему конусами. Здесь можно сохранить этот механизм, заменить локальное правило и увидеть, что меняют накопление, порядок пересчёта и маршрут вершин.

Конусное поле

Все пять кнопок работают с конусным полем. Число правила задаёт локальную таблицу, а не превращает этот опыт в обычный одномерный клеточный автомат из книги.

Память клетки

Изменение параметров начинает опыт заново. «По ходу» читает общее поле во время прохода; «Снимок» фиксирует его в начале. Одна вершина означает повторные проходы из того же места, а не один-единственный кадр.

Восемь переходов локального правила

Тройка — три клетки верхнего ряда: слева, по центру и справа от целевой клетки. Нажмите результат, чтобы переключить выходной бит. 1 — чёрный, 0 — белый; пустая клетка при вычислении считается нулём.

Кадр — это проход, а не новый ряд

Изначально поле пустое. В обычном маршруте вершины располагаются относительно якоря так: 0, −1, +1, −2, +2, … Каждый шаг проходит один конус сверху вниз и меняет клетки через одну. Вне конуса прежние значения остаются.

Базовый вариант «Наш 90» использует исходное ядро Маятника. Новое значение равно старому значению клетки XOR левый верхний сосед XOR правый верхний сосед. Верхние клетки читаются из общего поля: внутри конуса они уже пересчитаны, а за его границей могут хранить результат прежнего прохода. Пустая вершина сначала становится постоянной единицей. Уже записанная вершина временно принимается за единицу для первого нижнего ряда, затем её прежнее значение восстанавливается.

Для остальных правил таблица читает левую, центральную и правую клетки верхнего ряда. Накопление добавляет к её результату старое значение целевой клетки через XOR; без накопления результат заменяет прежнее значение. Верхний центр и старая целевая клетка — разные клетки.

Это наши гибридные конусные модели. Их нельзя отождествлять с обычными диаграммами одномерных автоматов Вольфрама по одному номеру правила или похожему рисунку. В режиме «Снимок» входы фиксируются в начале прохода после временной установки вершины в единицу; нижние ряды ещё содержат прежние значения. Дальнейшие изменения текущего прохода в снимок не попадают.

Работа без звука. Настройки хранятся в отдельном ключе этого раздела; после открытия выполнение всегда остановлено. Настройки прежнего Маятника не изменяются. Проверки вычислений, интерфейса и визуальная приёмка оставлены пользователю.
