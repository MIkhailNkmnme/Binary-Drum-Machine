# Оснастка: управление Зеркалиусом из скрипта

Скрипты открывают `Zerkalius-genezis.html` в Chromium через Playwright, жмут его
собственные кнопки, снимают кадры и собирают из них видео. Ничего в самом движке
не меняется — это внешний пульт.

## Что нужно

- Node 18+ и Playwright с Chromium: `npm i -D playwright && npx playwright install chromium`
- ffmpeg в `PATH` (или путь в переменной `FFMPEG`) — только для клипов
- локальный сервер в корне репозитория: `npx http-server -p 8080 -s .`

`vendor/pixi-7.4.2.min.js` лежит рядом, потому что WebGL-режим движка тянет Pixi
с CDN, а в закрытом окружении CDN недоступен: скрипты подменяют этот запрос
локальной копией. На живом сайте подмена не используется.

## Файлы

| файл | что делает |
|---|---|
| `controls-genezis.json` | карта 236 контролов движка: id, тип, подпись, диапазон |
| `recipes.js` | рецепты узоров: значения контролов + какие кнопки нажать |
| `run-sheet.js` | прогоняет все рецепты, кладёт кадры в `renders/sheet/` |
| `make-sheet.js` | собирает из кадров контактный лист `CONTACT-SHEET.png` |
| `clips.js` | рендерит выбранные рецепты в mp4 (`renders/clips/`) |
| `horror.js` | отдельная партия рецептов: хоррор-варианты и починенный XorRora |

## Как это снимает ровное движение

Движок крутит анимацию через `requestAnimationFrame`, а на софтверном GPU кадры
приходят неравномерно. Поэтому перед съёмкой скрипт подменяет `requestAnimationFrame`
и `performance.now()` виртуальными часами и сам продвигает время на 16 мс перед
каждым снимком. Получается ровно один логический шаг движка на кадр видео,
независимо от того, как быстро рисует машина.

## Рецепт

```js
{ id:'r04', name:'Воронка',
  set:{ sierpRule:'center', sierpSeed:'1011011', sierpRows:80, funnelCheck:true },
  click:['sierpBtn'],        // кнопки движка
  postClicks:['floatingCenterBtn'], // жмутся после скрытия панелей
  gl:true }                  // включить ⚡ WebGL
```

Ключи в `set` — это id контролов из `controls-genezis.json`.

## Кадрирование

Движок нарочно опускает сетку ниже пульта плеера и дотягивает этот сдвиг ещё
около полусекунды после генерации (см. `STATE.offsetY` и `recheckClearance`).
Скрипты панели прячут, поэтому сдвиг только мешает: в кадре оставалась чёрная
полоса примерно в 30% высоты.

Правило, при котором кадр заполняется целиком (замерено: 0.998 по обеим осям):

1. сначала «Сгенерировать», потом кегль и `screenSlider` — генерация затирает
   выставленное до неё;
2. видимых строк ровно `ceil(высота кадра / кегль) + 2`;
3. `STATE.offsetY/offsetX` и авто-смещения обнуляются **последним** действием
   перед съёмкой, уже после того как движок отработал свои дотяжки.

## Мастер под музыку

`master.js` привязывает шаг движка к долям такта: шаг делается только на кадрах,
попадающих на долю, между долями картинка стоит. Дрейфа нет — позиция доли
считается от начала, а не накоплением.

```
node tools/master.js --recipe k1 --bpm 128 --beats 64 --fps 30 --font 22
```

## Карта трека

`audio-map.py` считает темп, фазу первой доли и границы секций по тактам —
из этого строится раскладка сцен.

```
FFMPEG=/путь/к/ffmpeg python3 tools/audio-map.py трек.mp3
```

Темп ищется гребёнкой: для каждого кандидата BPM берётся лучшая фаза и
считается сумма onset-функции на долях. Автокорреляция для такой музыки врёт —
на «Laniakea» она уверенно выдавала 99.38 BPM, зацепившись за такт, тогда как
настоящий темп ровно 100.00.

Нужен numpy (`pip install numpy`).

## Музыка без ровной сетки

`onsets.py` находит моменты ударов и пишет их списком:

```
FFMPEG=... python3 tools/onsets.py трек.mp3 > steps.json
```

Дальше рендер шагает по ним, а не по долям:

```
node tools/master.js --recipe k1 --steps steps.json --seconds 24 --from 15 --fps 30
```

Это нужно там, где фиксированный темп не годится. У «Laniakea» доли ровные
(100.00 BPM, оценка 3.06), а у брейккора Venetian Snares оценка темпа 0.69 и
разброс интервалов между ударами почти равен самому интервалу — сетка плавает,
и привязка к долям разъезжается с музыкой уже на первом такте.

`--seconds` задаёт длительность напрямую, `--from` — с какой секунды трека
берётся кусок (чтобы вырезать удары именно этого отрезка).
