# Локальный помощник Зеркалиуса · ПОМ-001–004

Текстовая модель **gpt-oss:20b** работает через Ollama на этом компьютере.
Python-сервис использует только стандартную библиотеку. Облачных вызовов, загрузки
моделей и исполнения предложенных моделью команд нет. Модель объясняет документацию
и предлагает ограниченный набор настроек Маятника; применение остаётся отдельным
действием пользователя в панели. Этот помощник не генерирует звук или голос.

Компактное окно содержит поле ввода и ромбовые значки: `?` — объяснение, `◇` —
подбор настроек или действия, `↑` — отправить, `■` — остановить ожидание, `↶` —
отменить последние настройки, `⚙` — подключение, `×` — закрыть. Полные названия
доступны в подсказках и для экранного диктора. Ввод с Ctrl+Enter отправляет вопрос.
Подключение без ошибки не занимает отдельную строку. Ответы и предложения
появляются после вопроса; вступления и примеры убраны. Заголовок с `⠿` переносит
окно, его положение сохраняется. Приоритет в перекрытии определяется поверхностью,
откуда пришёл указатель. Выбор режима не меняется автоматически.

## Запуск в Windows

Из корня репозитория, в PowerShell:

```powershell
& .\tools\local-assistant\start.ps1
```

Для запуска сервиса и открытия публичного Маятника с панелью помощника одной командой:

```powershell
& .\tools\local-assistant\open.ps1
```

Если браузер блокирует доступ публичной страницы к loopback, используйте локальную
ссылку ниже. `open.ps1` принимает те же пути Python/Ollama/моделей и стандартный порт 11435.

Скрипт ищет Python в `C:\Python313`, затем `C:\Python312`, затем в PATH (без
WindowsApps). Требуется Python 3.10+. Ollama проверяется через локальный HTTP API;
если она не запущена, скрипт скрыто запускает `ollama.exe serve`, задавая
`OLLAMA_HOST=127.0.0.1:11434`. Не используется `ollama list`: на этой машине этот
вызов открывал настольный интерфейс и зависал. Уже запущенная Ollama не меняется.

По умолчанию каталог моделей — значение `OLLAMA_MODELS`, либо
`E:\OllamaModels\models`. Установка Ollama и модель должны уже существовать:
скрипт ничего не скачивает. Другие пути можно задать явно:

```powershell
& .\tools\local-assistant\start.ps1 -Python 'C:\Python313\python.exe' -OllamaExe "$env:LOCALAPPDATA\Programs\Ollama\ollama.exe" -Models 'E:\OllamaModels\models'
```

Адрес сервиса — `http://127.0.0.1:11435`; он слушает только IPv4 loopback.
Порты 8765/8766 уже заняты другими службами, поэтому здесь они не используются.
`-Port` позволяет выбрать иной порт, но адрес в панели тогда также нужно изменить.

Сайт `https://1001100.online` может запросить доступ к локальной сети. Возможность
обращения к HTTP loopback зависит от браузера и его разрешений. Если подключение
публичной страницы заблокировано, откройте локальную копию:

[Маятник на этом компьютере](http://127.0.0.1:11435/mayatnik/Zerkalius-mayatnik.html).
Она обслуживается прямо из текущего репозитория. `localhost` и `127.0.0.1` имеют
разные браузерные хранилища; настройки публичного сайта не переносятся автоматически.
Независимые внешние функции страницы могут по-прежнему обращаться к своим сервисам;
сам помощник обращается только к локальной Ollama.

```powershell
& .\tools\local-assistant\stop.ps1
# Также остановить Ollama, только если её запустил именно этот скрипт:
& .\tools\local-assistant\stop.ps1 -WithOllama
```

PID, время создания процесса и его путь сохраняются в
`%LOCALAPPDATA%\Zerkalius\assistant\service.json`. Перед остановкой они сверяются;
процессы с повторно использованным PID не останавливаются. Общая или самостоятельно
запущенная Ollama не останавливается. Там же находятся журналы запуска stdout/stderr.
Сервис не журналирует сообщения, историю, состояние, ответы или URL запросов.

## Какие сведения получает модель

Источники разделены по страницам. Сначала выбирается профиль, затем выполняется
поиск только внутри его документов и общих правил. Если подходящих сведений нет,
поиск не переключается на другую страницу.

| Профиль API | Страница | Её руководство |
| --- | --- | --- |
| `mayatnik` | Маятник | `mayatnik/instruction/index.html` |
| `genesis` | Zerkalius: Genesis (Бинарная Драм-Машина) | `README.ru.md` |
| `synthesis` | Маятник · Синтез | `mayatnik/synthesis-instruction.html` |

Общие нормативы для всех профилей: `КНОПКИ.md` и `ЗВУК.md`. Упоминание другой
страницы в общих правилах не означает наличия её кнопок на текущей странице.
README — руководство Genesis, **не устаревшее руководство Маятника**. Все исходные
руководства сохранены без изменения; раздел OBS/VJ остаётся в профиле Genesis.
Профили Genesis и Синтеза зарегистрированы в API для объяснений; интерфейс помощника
и применение настроек сейчас подключены только в Маятнике.

Дополнительный авторитетный источник для действий помощника — подписи и описания
`mayatnik/assistant-controls.json`, только в профиле `mayatnik`. Каждая настройка индексируется отдельно;
ссылка ведёт на раздел [Помощник](https://1001100.online/mayatnik/instruction/index.html#assistant).
При коротком уточнении учитываются слова последнего сообщения пользователя,
но они только уточняют порядок отрывков, совпавших с текущим запросом.

В этой версии отдельных Markdown-инструкций Маятника нет в списке: технические
протоколы проверок, AGENTS, журналы, секреты и произвольные файлы не индексируются.
HTML разбивается по заголовкам, текст — на короткие пересекающиеся отрывки.
Лексический поиск учитывает русские окончания через короткие основы слов и
приоритет заголовков. Это не полный семантический поиск и не обучение модели.
В ответ попадают проверенные ссылки на исходную страницу и её реальный якорь
заголовка, если он присутствует в HTML. Для Markdown ссылка ведёт на сам документ.

На запрос передаются до четырёх подходящих отрывков по 1400 знаков, актуальное
состояние разрешённых контролов, их общий JSON-справочник и два последних сообщения
истории (до 1000 знаков каждое). Остальная документация остаётся на диске. Изменения
документов подхватываются после перезапуска сервиса. Модель не видит экран, рисунок
поля, остальные настройки, историю Codex или весь репозиторий. Если вопрос зависит
от невидимого состояния, помощник должен попросить уточнение.

Ollama получает `num_ctx=8192`, `num_predict=2200`, `temperature=0.2`, `think=low`,
JSON-схему ответа и таймаут 175 секунд. Одновременно выполняется только один запрос;
второй получает 429. Большая модель может отвечать медленно. При сбое возвращается
честная ошибка; запасной ответ не имитирует работу модели. Ссылки подтверждают
происхождение отрывков, но смысловой вывод модели может потребовать проверки.

## Контракт API

`GET /api/health` возвращает `available`, `model`, `error`, `busy`, `documents`, `local`,
`knowledge_version` и `page_sources` — фактическую карту профилей и документов.
`documents` — число отрывков профиля Маятника, включая общие правила.
`available` означает, что в API Ollama видна модель `gpt-oss:20b` и доступен справочник
контролов. Это не пробный запрос генерации и не измерение качества ответа.

`POST /api/chat` требует `Content-Type: application/json`, тело до 65536 байт:

```json
{"page":"mayatnik","history_page":"mayatnik","knowledge_version":"page-actions-v2","message":"Как сделать движение медленнее?","mode":"settings","state":{},"history":[]}
```

`mode`: `explain` или `settings`; сообщение — до 4000 знаков. `history` содержит до
12 объектов `{role,content}` с ролями `user`/`assistant`, не более 4000 знаков на
сообщение и 12000 всего. В модель передаётся ограниченная недавняя часть истории.
`state` содержит **только** ID из `mayatnik/assistant-controls.json` с корректными
значениями. Неизвестный ID или значение вне диапазона отклоняется.

`page` — один из трёх профилей выше; неизвестная страница отклоняется. Для старого
клиента без `page` используется только Маятник, без смешанного набора источников.
У Genesis и Синтеза допустим только `explain`, состояние пустое. История учитывается,
только если `history_page` совпадает с `page`, а `knowledge_version` равна
`page-actions-v2`; прежняя история отбрасывается. История не служит
доказательством наличия функций. Ответ содержит `page` и `knowledge_version`;
клиент Маятника не показывает ответы другой страницы или прежней версии источников.

```json
{"answer":"Пояснение модели","changes":[],"actions":[],"sources":[{"title":"Заголовок","url":"https://1001100.online/mayatnik/instruction/index.html"}],"model":"gpt-oss:20b","page":"mayatnik","knowledge_version":"page-actions-v2"}
```

В `explain` изменения и действия всегда пусты. В `settings` каждое предложение имеет
`{id,value,reason}`; допускаются до восьми разных контролов. Сервер проверяет ID,
тип, диапазон, шаг числа, варианты select, цвет `#RRGGBB` и непустую причину.
Для непустых предложений обязательны ссылки на реально переданные выдержки.
Общий справочник версии 1 имеет формат
`{version:1,controls:[{id,label,type,min,max,step,options:[{value,label}],description}],actions:[{id,label,description}]}`;
неприменимые поля необязательны. Этот же справочник использует клиент. Сервер
ничего не применяет к приложению и не доверяет настройкам из текста ответа.

Отдельно разрешено одно действие только в `mayatnik/settings`:
`actions:[{id:"paintAutoAxes",reason:"…"}]`. Оно не совмещается с `changes`.
Это разовая раскраска текущего кадра **только от автоматических осей**, текущим
цветом «От осей», с текущими параметрами «Область» и «Зеркально». Действие
останавливает кадр и включает автооси. Ручные оси не служат источником этой команды;
цвет и режим непрерывной раскраски не меняются. Модель предлагает действие,
клиент показывает последствия, и только отдельный ромб `✓` подтверждает его.

Перед отправкой вопроса клиент получает у ядра непрозрачный контекстный токен.
Он остаётся в памяти клиента: не передаётся серверу, модели, истории или localStorage.
Ядро сверяет текущие кадр, поле, настройки и краску с сохранённым контекстом перед
запуском. Устаревшее предложение требует нового запроса. Результат `changed`
может быть флагом либо числом окрашенных пикселей; нулевой результат и ошибки
выводятся честно вместе с сообщением ядра о побочных изменениях состояния.
Для отмены раскраски используется штатная **«Отмена» в группе «Раскраска»**;
`↶` помощника относится только к изменениям настроек. В режиме `?` просьба
выполнить действие получает подсказку перейти в `◇` и повторить вопрос.

Ошибка имеет формат `{error,model}` и HTTP 400, 403, 404, 413, 415, 429, 502 или 503.
Некорректный ответ модели целиком отклоняется; выдуманные настройки не исправляются
молча. Ответ без подходящих выдержек может объяснить нехватку сведений, но не должен
предлагать настройки.

## Границы доступа

Проверяются Host (`localhost:порт` / `127.0.0.1:порт`) и точный Origin. Разрешены
`https://1001100.online`, `https://www.1001100.online`,
`https://mikhailnkmnme.github.io` и HTTP-источники localhost/127.0.0.1 с обычным портом.
`null`, поддомены и похожие имена не разрешены. OPTIONS поддерживает preflight
Private Network Access. Сервис не использует cookie или токены и не слушает сеть
офиса. Доступ любого процесса на самом компьютере не является границей изоляции.

Локальная раздача ограничена каталогами `mayatnik`, `_js`, `_fonts`, `_img`, `assets`,
`zazerkalius`, `azbuk` и типами HTML/JS/CSS/JSON/изображений/шрифтов. Листинга каталогов
нет; dot-пути, выход за корень, символьные ссылки и junction запрещены. `tools`,
`.git`, `.local-secrets`, Markdown-журналы и прочие корни не раздаются. Файл больше
32 МБ не раздаётся. Это локальный вспомогательный сервер, не сервер публикации.
Сама эта памятка расположена в закрытом для локальной раздачи каталоге `tools`;
из панели следует открывать её [публичную копию на GitHub](https://github.com/MIkhailNkmnme/Binary-Drum-Machine/blob/main/tools/local-assistant/README.md).

Реализация прочитана вручную. Автотесты, синтаксические проверки, генерация моделью
и браузерная приёмка не запускались: проверки остаются пользователю по AGENTS.md.

## Постоянная раскраска без помощника · ПОМ-005

В Маятнике1.055 для пересчёта на каждом кадре используется native переключатель
**Оси → Симметрия → Автоокраска**, под «Автооси ▼». Рядом свой цвет,
Область/Зеркально берутся из Раскраски. Включение включает автооси; выключение
снимает только временный слой, не ручную краску. Это самостоятельный режим
страницы. Контракт `paintAutoAxes` помощника остаётся разовым действием.
