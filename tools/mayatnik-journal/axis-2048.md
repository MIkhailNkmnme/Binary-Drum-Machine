# Фигуры центральной оси на 2048 строках

Обычный Маятник строится штатным ядром на пустом поле 6 142 × 2 048 клеток. Центральный столбец имеет индекс 3 071. Сохранены 512 кадров, с 4 по 2048 с шагом 4. [Открыть исходное поле](https://1001100.online/mayatnik/Zerkalius-mayatnik.html?chisto&n=2048&s=2048&k=4&mode=pend)

В каждом кадре выделены все связные по стороне или углу группы одинаковых битов, касающиеся центрального столбца. Одинаковая фигура при переносе хранится один раз. Кадр, координаты и размеры сохранены для каждого вхождения. Нумерация координат с нуля, от левого верхнего угла.

Полный расчёт дал 8 903 уникальные фигуры и 66 166 вхождений. Вставляемый банк содержит 7 830 фигур и 65 093 вхождения. В каталоге крупных фигур 1 073 фигуры.

В Битотеке откройте «Шаблоны» → «2048» → «Атлас» для вставки фигур. Банк загружает фигуры до 4 096 занятых клеток и 12 млн клеток габаритного прямоугольника. Остальные доступны через «Крупные фигуры» и в полном ZIP. Пользовательская настройка площади по умолчанию отключена. [Каталог крупных фигур](https://1001100.online/mayatnik/axis-2048/)

В ZIP лежат исходные PNG кадров и фигур, `index.json` с SHA-256 каждого файла и `occurrences.csv` со всеми вхождениями. Номер фигуры в каталоге совпадает с номером её PNG. [Скачать полный атлас](https://github.com/MIkhailNkmnme/Binary-Drum-Machine/releases/download/mayatnik-axis-2048/mayatnik-axis-2048.zip)

## Воспроизведение

Из корня репозитория выполните следующие команды с Node.js 22 или новее и Python с Pillow. Первая проверяет покрытие оси, упаковывает точные PNG и записывает `mayatnik/mayatnik-axis-2048-data.js`. Вторая сверяет файлы с SHA-256 индекса, собирает ZIP и превью.

```sh
node tools/mayatnik-journal/build-axis-1024.cjs '<папка атласа 2048>' 2048
python3 tools/mayatnik-journal/publish-axis-1024.py '<папка атласа 2048>' '<новый файл mayatnik-axis-2048.zip>'
```
