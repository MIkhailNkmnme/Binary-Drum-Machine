# Сплошной поиск строк 30–70 в Ромбомаятнике

Из корня репозитория с Node.js 20 или новее:

```sh
node tools/mayatnik-journal/search-rhomb-contiguous.cjs --plan
node tools/mayatnik-journal/search-rhomb-contiguous.cjs
```

На рабочем компьютере с приложением ChatGPT для Linux вместо `node` также подходит `/usr/lib/chatgpt/resources/node`.

Основной прогон включает 360 настроек до N = 1024 и до 1 018 800 кадров. Берутся фиксированные поля, отскок, XOR и AND. Поиск идёт по четырём направлениям со стартового кадра до конца одного периода **движения** каждого маршрута. Полный повтор битового рисунка может наступить позже. Спирали в этом расчёте пропущены. Каждая длина от 30 до 70 снимается с поиска после первого совпадения в данной настройке.

Расчёт воспроизводит горизонтальные границы Ромбомаятника v0.051 из опубликованной выборки. Опорные кадры предыдущего выпуска этого скрипта подходят для продолжения.

По умолчанию данные пишутся в папку `romb-search-1024` домашнего каталога. Чтобы остановиться, нажмите **Ctrl+C**. Скрипт завершит текущие кадры, сохранит опорные кадры и соберёт общий `results.json` из законченных вариантов. Та же команда с той же папкой продолжит расчёт. Первые совпадения в незаконченных вариантах хранятся в опорных кадрах. При аварийном завершении опорные кадры сохраняются с последней записи. Если остался `run.lock`, проверьте, что процесса с записанным в нём PID больше нет, затем удалите только этот файл.

Можно указать другую папку через `--output ПУТЬ` или число рабочих потоков через `--workers 1`. Число потоков можно менять между запусками. Для короткого самостоятельного расчёта:

```sh
node tools/mayatnik-journal/search-rhomb-contiguous.cjs --max-size 64 --max-frames 32
```

В `results.json` для каждой завершённой настройки указан диапазон от кадра 1 до `checked` включительно и первые совпадения с координатами начала и конца. Координаты отсчитываются от 1 в исходной решётке.
