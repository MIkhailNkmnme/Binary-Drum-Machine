# Сплошной поиск строк 30–70 в Ромбомаятнике

Из корня репозитория с Node.js 20 или новее:

```sh
node tools/mayatnik-journal/search-rhomb-contiguous.cjs --plan
node tools/mayatnik-journal/search-rhomb-contiguous.cjs
```

На рабочем компьютере с приложением ChatGPT для Linux вместо `node` также подходит `/usr/lib/chatgpt/resources/node`.

Поиск идёт по четырём направлениям со стартового кадра до конца одного периода **движения** каждого маршрута. Полный повтор битового рисунка может наступить позже. В наборе 360 настроек до N = 1024 с фиксированными полями, отскоком, XOR и AND. Спирали в этом расчёте пропущены. Каждая длина от 30 до 70 снимается с поиска после первого совпадения в данной настройке.

Чтобы использовать границы v0.052, при которых целый ромб помещается в поле, добавьте `--whole`:

```sh
node tools/mayatnik-journal/search-rhomb-contiguous.cjs --whole --plan
node tools/mayatnik-journal/search-rhomb-contiguous.cjs --whole
```

С `--whole` первыми идут 192 одноосевых варианта, до 161 040 кадров. Полный план насчитывает до 268 189 968 кадров. Период общего маршрута в четыре раза больше наименьшего общего кратного периодов двух осей. Версия без `--whole` воспроизводит горизонтальные границы опубликованной выборки v0.051 и охватывает до 1 018 800 кадров. Опорные кадры прежних выпусков скрипта подходят для продолжения этого расчёта.

По умолчанию расчёт с `--whole` пишет данные в папку `romb-search-1024-whole` домашнего каталога. Для прежней геометрии используется `romb-search-1024`. Чтобы остановиться, нажмите **Ctrl+C**. Скрипт завершит текущие кадры, сохранит опорные кадры и соберёт общий `results.json` из законченных вариантов. Та же команда с той же папкой продолжит расчёт. Первые совпадения сразу видны в журнале вывода. Завершённые варианты записываются в отдельные `result-*.json`. Первые совпадения в незаконченных вариантах хранятся в опорных кадрах. При аварийном завершении опорные кадры сохраняются с последней записи. Если остался `run.lock`, проверьте, что процесса с записанным в нём PID больше нет, затем удалите только этот файл.

Можно указать другую папку через `--output ПУТЬ` или число рабочих потоков через `--workers 1`. Число потоков можно менять между запусками. Для короткого самостоятельного расчёта:

```sh
node tools/mayatnik-journal/search-rhomb-contiguous.cjs --whole --max-size 64 --max-frames 32
```

В `results.json` для каждой завершённой настройки указан диапазон от кадра 1 до `checked` включительно и первые совпадения с координатами начала и конца. Координаты отсчитываются от 1 в исходной решётке.
