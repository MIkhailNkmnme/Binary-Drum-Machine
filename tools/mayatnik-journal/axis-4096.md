# Фигуры центральной оси на 4096 строках

Обычный Маятник строится на пустом поле 12 286 × 4 096 клеток. Центральный столбец имеет индекс 6 143. Сохранены 1 024 кадра, с 4 по 4096 с шагом 4. [Открыть исходное поле](https://1001100.online/mayatnik/Zerkalius-mayatnik.html?chisto&n=4096&s=4096&k=4&mode=pend)

В каждом кадре выделены все связные по стороне или углу группы одинаковых битов, касающиеся центрального столбца. Одинаковая фигура при переносе хранится один раз. Кадр, координаты и размеры записаны для каждого вхождения. Координаты отсчитываются от левого верхнего угла с нуля.

Полный расчёт дал 28 284 уникальные фигуры и 266 750 вхождений. В Битотеке доступны 26 143 фигуры. В каталоге крупных фигур 2 141 карточка.

В Битотеке откройте «Шаблоны» → «4096» и выберите папку по номерам. Вставляемый банк включает фигуры до 4 096 занятых клеток и 12 млн клеток габаритного прямоугольника. Крупные фигуры можно рассмотреть в каталоге и скачать в точном размере из архива. Пользовательский лимит площади выделения на поле по умолчанию отключён. [Каталог крупных фигур](https://1001100.online/mayatnik/axis-4096/)

Части ZIP пронумерованы. В каждой лежат указанные в каталоге PNG и общие `index.json` с SHA-256 файлов и `occurrences.csv` со всеми вхождениями. Номер карточки в каталоге совпадает с номером PNG. [Архивы полного расчёта](https://github.com/MIkhailNkmnme/Binary-Drum-Machine/releases/tag/mayatnik-axis-4096)

## Воспроизведение

Из корня репозитория выполните команды с Node.js 22 или новее и Python с Pillow.

```sh
node tools/mayatnik-journal/build-axis-1024.cjs '<папка атласа 4096>' 4096
python3 tools/mayatnik-journal/publish-axis-1024.py '<папка атласа 4096>' '<папка атласа 4096>/mayatnik-axis-4096.zip'
```

Генератор проверяет покрытие центрального столбца, совпадение повторов и обратимость упаковки PNG. Упаковщик сверяет SHA-256 PNG при записи и чтении каждого ZIP и вычисляет SHA-256 частей. Последняя команда создаёт нумерованные ZIP, `archive-parts.json` и файлы каталога.
