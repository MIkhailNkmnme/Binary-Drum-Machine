# Публикация кадров Маятника

Кнопка «PNG в журнал» отправляет PNG по HTTPS на `media.1001100.online/mayatnik-api/frames`. Worker пишет оригинал в `from-mayatnik/` существующего R2-бакета `zerkalius-media`. Запись сразу появляется в API журнала. Раздел «Из Маятника» запрашивает по 24 кадра, начиная с новых. Клиент передаёт PNG, текст параметров и код состояния в multipart. Worker сохраняет код отдельно по SHA-256, затем записывает PNG с описанием и ссылкой на состояние в метаданных. Старые клиенты могут отправлять PNG отдельно.

На один IP действует скользящее окно в 60 секунд. Durable Object резервирует до 10 попыток загрузки до проверки и записи растра. Cloudflare сообщает IP на входе. При исчерпании лимита сервер возвращает HTTP 429 и время ожидания. Исходные IP не записываются в метаданные кадров. Ограничения одной публикации — 8 МиБ и 32 Мпикс.

Из этой папки выполните `npx wrangler@4 deploy` под учётной записью Cloudflare, управляющей Workers и маршрутами зоны 1001100.online. Конфигурация использует привязку R2. После доставки `GET https://media.1001100.online/mayatnik-api/frames` должен возвращать JSON с полями `frames` и `cursor`.

Резервный адрес — https://zerkalius-mayatnik-journal.zerkalius-1001100.workers.dev. На нём тот же Worker читает и пишет тот же R2-префикс, выдаёт оригиналы и использует тот же лимит. Перед отправкой клиент получает имя PNG от сервера. При потере ответа повторяет отправку с тем же именем, условная запись R2 сохраняет единственную карточку.

Вход редактора использует секрет Worker `JOURNAL_EDITOR_PASSWORD_HASH` с SHA-256 от пароля в нижнем регистре (hex). Сеанс длится четыре часа. Кнопка «Удалить» снимает картинку с публикации. Для загруженного кадра она также удаляет PNG из R2. Для архивной иллюстрации сохраняется общий исходный файл, который могут использовать другие страницы.
