# Публикация кадров Маятника

Кнопка «PNG в журнал» отправляет PNG по HTTPS на `media.1001100.online/mayatnik-api/frames`. Worker пишет оригинал в `from-mayatnik/` существующего R2-бакета `zerkalius-media`. Запись сразу появляется в API журнала. Раздел «Из Маятника» запрашивает по 24 кадра, начиная с новых. Одна операция R2 сохраняет картинку и данные карточки вместе.

На один IP действует скользящее окно в 60 секунд. Durable Object резервирует до 10 попыток загрузки до проверки и записи растра. Cloudflare сообщает IP на входе. При исчерпании лимита сервер возвращает HTTP 429 и время ожидания. Исходные IP не записываются в метаданные кадров. Ограничения одной публикации — 8 МиБ и 32 Мпикс.

Из этой папки выполните `npx wrangler@4 deploy` под учётной записью Cloudflare, управляющей Workers и маршрутами зоны 1001100.online. Конфигурация использует привязку R2. После доставки `GET https://media.1001100.online/mayatnik-api/frames` должен возвращать JSON с полями `frames` и `cursor`.
