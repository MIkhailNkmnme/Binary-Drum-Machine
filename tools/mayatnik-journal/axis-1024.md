# Фигуры центральной оси на 1024 строках

Обычный «Маятник» строится штатным ядром на пустом поле 3070 × 1024. Центральный столбец имеет индекс 1535. Параметры построения — 1024 строки, 1024 хода, режим «Маятник». В наборе все 256 кадров с 4 по 1024 с шагом 4. [Открыть кадр 1024 в Маятнике](https://1001100.online/mayatnik/Zerkalius-mayatnik.html?chisto&n=1024&s=1024&k=1024&mode=pend).

В каждом кадре берём все группы одинаковых битов, которые имеют хотя бы одну клетку в центральном столбце. Клетки связаны по стороне или углу. При сравнении фигур учитываются габариты, все занятые клетки и значение бита. Одинаковый узор при переносе сохраняется один раз, с каждым из его вхождений. Повороты, отражения и смена значения бита дают совпадение только при полном совпадении полученной маски и значения.

| Набор | Кадры | Уникальные фигуры | Вхождения |
|---|---:|---:|---:|
| 512, весь GIF | 194 | 269 | 300 |
| 1024, локальный атлас | 256 | 2847 | 16372 |
| 1024, шаблоны Маятника | 256 | 2311 | 15836 |

Атлас 512 выделяет фигуры по всему кадру исходного GIF и допускает соединение битов 0 и 1 внутри одной фигуры. Атлас 1024 выделяет одноцветные компоненты через центральный столбец числового поля. Количества относятся к разным правилам отбора.

Банк для сайта включает фигуры до 4096 занятых клеток и прямоугольника до 12 млн клеток. Остальные 536 фигур и их 536 вхождений сохранены в локальном наборе. У самой крупной фигуры 1 607 222 занятые клетки.

## Файлы и воспроизведение

Локальный атлас находится в папке «обои Зеркалиус → Фигуры центральной оси → 1024».

- `frames/` — полный кадр 3070 × 1024 в каждом файле, один пиксель на клетку.
- `figures/` — отдельный точный PNG каждой уникальной фигуры.
- `index.json` — параметры, ссылки на кадры, контрольные суммы PNG и все вхождения.
- `occurrences.csv` — строки с кадром, координатами, габаритами, числами битов и ссылкой на PNG фигуры.

Координаты вхождений отсчитываются от верхнего левого угла поля, начиная с нуля. Пустые клетки прозрачны. Бит 0 тёмно-синий, бит 1 светло-жёлтый.

Генератор запускается из корня репозитория на Node.js с функцией `zlib.crc32`. Для этого набора использовалась версия 22.16.0.

```
node tools/mayatnik-journal/build-axis-1024.cjs "<путь к локальной папке атласа>"
```

Генератор сверяет, что учтены все занятые клетки центрального столбца, а число вхождений совпадает в индексах кадров и фигур. Для совпавших масок он проверяет точное равенство пикселей после распаковки. Строки каждого PNG проходят обратную распаковку перед записью. Повторный запуск сверяет существующие локальные файлы побайтово и дописывает недостающие. Банк сайта создаётся в `mayatnik/mayatnik-axis-1024-data.js`, PNG остаются вне Git.
