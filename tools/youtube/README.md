# Инструментарий YouTube

Три скрипта, которыми сделаны публикации 17 ноября 2026. Работают через Selenium и копию профиля
Firefox с входом в Google — API и OAuth не нужны.

## Что где

| Файл | Назначение |
|---|---|
| `render-page.html` | страница-рендерер: два маятника + художественный слой Синтеза, пишет холст в WebM через MediaRecorder |
| `record_video.py` | открывает страницу в Selenium, ждёт готовый файл в папке загрузок |
| `upload_batch.py` | пакетная загрузка: файл → название → описание → «Опубликовать» |
| `publish_drafts.py` | доводит уже созданные черновики: опознаёт по имени файла в заголовке, заполняет поля, публикует |

## Порядок работы

```powershell
# 1. Копия профиля Firefox с входом в Google (куки в репозиторий не попадают)
robocopy "$env:APPDATA\Mozilla\Firefox\Profiles\<профиль>" "E:\NineToZero\ff-prof" /E /XD cache2 startupCache crashes /XF parent.lock

# 2. Видео: запись и сборка
python tools/youtube/record_video.py 96 "&op=or&palette=nocturne&trail=8"
ffmpeg -i mayatnik-video.webm -i track.wav -c:v libx264 -crf 20 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest out.mp4

# 3. Загрузка
python tools/youtube/upload_batch.py
```

## Грабли, на которые уже наступили

- **Заголовок может остаться именем файла.** Studio подставляет имя файла, а вставка в поле названия
  иногда не срабатывает молча. Всегда читайте поле после вставки: если текст равен имени файла —
  вставка не прошла.
- **Описание не принимает Ctrl+V.** В редакторе видео вставка в описание может дать 0 символов.
  Рабочий резерв — `document.execCommand('insertText')` после `focus()`, он есть в `publish_drafts.py`.
- **Кнопки появляются позже, чем кажется.** «Редактировать черновик» на списке видео может не быть
  через 14 секунд: ждать до 40 и опрашивать.
- **Мастер не пускает дальше без ответа про детей.** Вопрос обязательный; без него «Далее» не работает,
  и шаг «Открытый доступ» не появляется.
- **Публичный вариант в русском Studio называется «Открытый доступ»**, а не «Публичный».
- **Черновики остаются при сбое.** Это нормально: `publish_drafts.py` их добирает, а не создаёт заново.

## Ограничения

- Селекторы YouTube Studio не документированы и меняются: при крупном обновлении интерфейса скрипты
  придётся править.
- Скрипты рассчитаны на русский интерфейс Studio (тексты кнопок — по-русски).
- Профиль и куки живут вне репозитория; после работы копию профиля удалять.
