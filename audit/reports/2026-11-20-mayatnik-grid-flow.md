# МАЯ-690 · Потоки по битовой сетке

Маятник v1.041, инструкция v0.152. Реализация; проверки пользователем.

Запрос: режим, где поток идёт сверху по каждому биту сетки и учитывает масштаб.

## Реализация

В группе Потоки добавлен переключатель «По сетке» с постоянным ключом flow-grid. Существующие ключи flow-N и раскладка не перенумерованы. Состояние сохраняется в mayatnik-flow-v1. По сетке, От оси и Солнце согласованы: включение сетки выключает последние два, включение любого из них выключает сетку.

Источники проходят через экранные центры битовых столбцов исходного поля; для обычной решётки шаг scale(), а не scale()/RK. Обрезаются индексы исходной решётки по viewport, её фаза сохраняется при панорамировании. Поворот180 преобразует x, направление остаётся экранным сверху вниз. Ромбы всего поля имеют целочисленные центры, обычные клетки — полуцелые; промежуток пары ромбических полей исключён. Для смещённых рядов используется объединение двух семейств центров с шагом полклетки. Это не обещание, что одна вертикаль проходит центры обеих чередующихся строк.

Неплотный свет подаётся целыми рядами с частотой1/с при скорости1: прежний лимит350 не отбрасывает правые столбцы. Ограничен бюджет ветвлений, возраст лучей остаётся8с собственного времени. Плотный свет получает явный список источников topBeams и рисуется отдельными непрерывными линиями. Прежний вызов topBeams без списка сохраняет сплошной экранный источник Хаба. Снег/вода подаются целыми рядами12/с, плотная вода — на шагах симуляции. Физика отражений, прохождения углов и перераспределения воды не изменена.

При смене масштаба/положения/геометрии сетки накопления и лучи сбрасываются, чтобы старые следы не оставались между новыми столбцами. Шаблоны и зеркальные копии участвуют в маске, но не добавляют источники. На мелком масштабе источники воды/снега могут попадать в одну клетку симуляции и сливаться; статус и инструкция объясняют предел. Более4096 видимых вертикалей — явная приостановка с просьбой увеличить масштаб, без скрытого пропуска столбцов.

## Фактическая проверка

Чтение исходников и diff root, независимое чтение геометрии внутренним flow_port. Автотесты, синтаксические проверки, приложение и браузер не запускались согласно AGENTS.md. Визуальная приёмка и производительность на пользовательском поле не подтверждены; проверки пользователем. Публикация и HTTP фиксируются отдельно в 2026-11-20-mayatnik-grid-flow-delivery.json.

Для пользовательской приёмки: включить Свет → По сетке, менять масштаб и сдвиг, переключить Плотно, проверить воду/снег, поворот180 и смещённые ряды; после F5 проверить сохранение переключателя. Приёмка не выполнена исполнителем.
