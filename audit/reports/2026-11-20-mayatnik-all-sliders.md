# МАЯ-693 / КНП-022 — числовые ползунки Маятника

Маятник v1.044, стандарт кнопок v229. Статус: реализация подготовлена, проверки пользователем.

По уточнению пользователя текст и число располагаются рядом с бегунком: слева, если хватает места; иначе справа. Если подпись длиннее обоих свободных участков, выбирается больший участок, размер подписи подгоняется без перекрытия метки. Это заменяет прежнее центрирование v228.

Общий адаптер охватывает обычные grozd-ползунки, ZerkControlFrame (включая «Пределы»), скорость, динамические панели, размер в «Хорр» и задержку GIF. Геометрия 120×24, боковые ромбы с тонкими стрелками, пунктирная вертикальная метка. Редактируемое число размера остаётся полем ввода. Шаги, диапазоны, сохранение и смысл значений сохранены; задержка GIF получила боковые шаги по 10 мс и удержание.

Специальные кадровые/транспортные контролы, период Тепла, цветовые диапазоны, вертикальные музыкальные фейдеры и XORROM 120×20 сохраняют отдельные правила. Общие компоненты grozd/control-frame не изменены. Новый адаптер включён только атрибутом живой страницы; замороженные страницы не переведены. Ручки Солнца исключены из механизма мини-кнопок.

Снимок исходного состояния: [Пределы](2026-11-20-mayatnik-all-sliders.png).

Root прочитал итоговые изменения. Внутренний flow_port выполнил инвентаризацию, UI задержки GIF и частичное независимое чтение. Его замечание об ограничении CSS живой страницей учтено. Финальная независимая рецензия не завершена из-за недоступности исполнителя; итоговое чтение выполнил root.

По AGENTS.md тесты, синтаксические проверки, приложение, браузер и визуальная приёмка не запускались. Положение подписей на крайних значениях, в скрываемых панелях и при изменении масштаба интерфейса проверяет пользователь. Доставка фиксируется отдельно в 2026-11-20-mayatnik-all-sliders-delivery.json.
