# Bit-Byte · v0.029

[Открыть](https://1001100.online/bit-byte/).

Четыре вкладки исследуют значения слов; пятая «Шахматки» управляет отдельными полями:

| Вкладка | Поле | Значения | Подписи осей |
| --- | --- | --- | --- |
| Байт | 16 × 16 | 256 слов по 8 бит: `00000000`–`11111111` | HEX и 4 бита, например `9 (1001)` |
| Полубайт | 4 × 4 | 16 слов по 4 бита: `0000`–`1111` | HEX и 2 бита, от `0 (00)` до `3 (11)` |
| Четвертьбайт | 2 × 2 | 4 слова по 2 бита: `00`, `01`, `10`, `11` | HEX и 1 бит: `0 (0)`, `1 (1)` |
| Бит | Шахматка 2 × 2 | `0` в (0, 0), `1` в (1, 1), две пустые клетки | Координаты 0/1 |

Для слов длиной 8, 4 и 2 бита строка задаёт ровно старшую половину слова, столбец — младшую. Разряды не округляются: правило требует чётной длины. Название вкладки «Четвертьбайт» выбрано пользователем; технический термин «дибит» указан в подсказке. У каждой вкладки свои исключения, расположение, отмена, ввод списка, сквозная и статистика. Переключение вкладки не изменяет данные другой; прежние сохранения сохраняются.

Во вкладке **Бит** показана схема `0 · / · 1`: чёрный 0 на пересечении координат 0 и 0, белая 1 на пересечении 1 и 1. Две клетки с разными координатами пустые. Щелчок по 0 или 1 исключает или возвращает этот бит. В итоги, сквозную и частоты входят только значения 0 и 1. Таблицы «По строкам» и «По столбцам» для этой схемы скрыты.

- Слева — исключение байтов; справа — расположение поля.
- Горизонтальный и вертикальный развороты — две независимые половины одной кнопки стандартного размера: слева `↔ Стлб`, справа `↕ Стр`. Третьей команды разворота нет.
- «Столбцы» обращает горизонтальный порядок 0…F ↔ F…0 (0…3 ↔ 3…0 для полубайта).
- «Строки» обращает вертикальный порядок 0…F ↔ F…0 (0…3 ↔ 3…0 для полубайта).
- У четвертьбайта и однобитной шахматки обе оси обращаются 0 ↔ 1.
- Обе включённые половины разворачивают обе оси: противоположные углы меняются местами (поворот расположения на 180°, не обмен строк со столбцами).
- «Исходно» возвращает обе оси к возрастающему порядку. Исключения сохраняются.
- Сквозная строка под полем склеивает оставшиеся байты по текущему расположению, слева направо и сверху вниз. Пробелы, разделители и дополнительные биты не вставляются. Ведущие нули каждого байта сохраняются. Переносы в текстовом поле только визуальные.
- У однобитной шахматки «Сквозная состояний» пропускает пустые клетки и исключённые биты. При исходном расположении и обоих активных битах получается `01`.
- При развороте меняется порядок байтов, а не порядок битов внутри каждого байта. Статистика строк/столбцов переставляется вместе с осями у таблиц 8/4/2 бита; итоги по выборке не меняются.
- Клавиши-стрелки следуют видимому направлению. Копирование сквозной строки выполняется только по кнопке; если буфер обмена недоступен, строка выделяется для Ctrl+C.

Исключения байтов сохраняются в прежнем `zerk_bit_byte_v1`, ориентация отдельно в `zerk_bit_byte_layout_v1`. У полубайтов ключи `zerk_bit_nibble_v1` и `zerk_bit_nibble_layout_v1`. Новым вкладкам выделены префиксы `zerk_bit_dibit` и `zerk_bit_bit` с теми же суффиксами. Последняя вкладка сохраняется в `zerk_bit_byte_active_tab_v1`. Отмена относится к последнему изменению исключений своей вкладки; история отмены и черновик списка живут до перезагрузки страницы. Вкладки доступны мышью и с клавиатуры (стрелки по кругу через все пять, Home, End).

## Статистика сквозной

Кнопка «Кольцевать» включает и отключает замыкание последнего бита на первый для всех расчётов сквозной. По умолчанию включена; режим сохраняется раздельно: префикс своей вкладки и суффикс `_cyclic_v1`. Сам скопированный текст не получает повторного первого бита и дополнительных разделителей.

- Таблица серий показывает количество максимальных непрерывных серий каждой точной длины: одиночные 1/0, двойные, тройные и далее до наибольшей найденной длины. Например, `111` учитывается в длине 3, а не в длинах 1 и 2.
- При включённом кольце первая и последняя серии объединяются, когда состоят из одного бита. В линейном режиме они раздельные. Между байтами разрывов нет; исключённые байты удалены до расчёта.
- Для каждой длины отдельно показаны серии единиц и нулей, внизу — сумма серий и сумма содержащихся в них битов.
- Переходы 1→0 и 0→1 учитывают каждую соседнюю пару; последняя и первая позиции соседние только при включённом кольце. На двоичном кольце их количества равны; в линейной строке могут отличаться на один. Для однородной последовательности обе величины нулевые.
- Однородное кольцо считается одной серией длины полного обхода. Пустая последовательность даёт нулевые итоги без серий.
- Таблицы пересчитываются вместе со сквозной при исключении, восстановлении, отмене и смене расположения поля. Обычные суммы битов и байтов сохраняют тот же смысл: замыкание не добавляет битов.

## Все значения в сквозной

Таблица показывает все значения выбранного размера слова: 256, 16, 4 или 2, в том числе отсутствующие (с нулевыми количествами).

- Столбцы сдвигов: 0–7 для байта, 0–3 для полубайта, 0–1 для четвертьбайта, только 0 для бита. Сдвиг — позиция первого бита относительно начала сквозной. Внутри каждого столбца шаг равен длине слова: 8, 4, 2 или 1 бит.
- «Всего» складывает количества по сдвигам: это все перекрывающиеся окна с шагом один бит. Исключённое из поля значение может встречаться в окнах через границы соседних оставшихся слов.
- При включённом кольце учитываются окна через стык конца с началом; для непустой сквозной число окон равно числу битов `N`.
- Без кольца учитываются только полные окна внутри строки: `max(0, N−k+1)`, где `k` — длина слова. Для бита число окон равно `N` в обоих режимах. Нули не добавляются.
- Внизу — сумма по каждому сдвигу и общий итог. Все количества обновляются при изменении исключений, расположения и кольцевого режима своей вкладки.

Проверки приложения и визуальная приёмка оставлены пользователю по AGENTS.md. Изменения просмотрены по коду; автоматические прогоны не выполнялись.


## Шахматки

Отдельное поле до 16 шахматок. Каждая клетка содержит один бит. Ползунок «Клетка, px» задаёт общую сторону клетки от 1 до 64 CSS px.

- Цветные квадраты в меню выбирают шахматку по цвету её обводки. Ctrl+щелчок по шахматке или квадрату добавляет её к выделению или убирает из него. Главная выделенная шахматка показана сплошной обводкой, остальные — пунктиром. Настройки меняют главную шахматку. Цвет рамки, цвет 0 и цвет 1 можно задать тремя соседними квадратами. Непрозрачность 0 и 1 настраивается отдельно.
- «Ромбо» добавляет шахматку из трёх ромбов, сходящихся в центре. Форма составлена из целых клеток. Пустые участки входят в расчёт наложения как участки за границей шахматки. Размер, цвета, видимость и форма сохраняются в кадрах.
- Край или угол меняет ширину и высоту в пределах 1–128 клеток. Противоположный край остаётся на месте. Общие клетки сохраняют цвет при растягивании слева или сверху.
- Обычное перетаскивание изнутри переносит одну верхнюю шахматку под указателем. Shift+перетаскивание выделенной шахматки переносит группу, Ctrl+перетаскивание переносит её копии с теми же параметрами. Жест с модификатором на шахматке вне выделения относится к ней одной. Если для всех копий не хватает места, выделение сохраняется. Сдвиг привязан к клеткам и сохраняет расстояния. X/Y обозначают координаты левого верхнего угла от 0 до 512. Escape отменяет начатый жест.
- Правый щелчок меняет 0 и 1 местами у верхней шахматки под указателем; двойной щелчок и двойное касание больше не инвертируют её. Есть та же команда в меню. «Цифры» включает контрастные 0 и 1 в клетках.
- «Автовыс.» держит нижнюю границу на одну клетку ниже самой нижней видимой шахматки. При пустом поле высота равна одной клетке. Ползунок высоты и перетаскивание нижней рамки переходят в ручной режим при изменении высоты. Режим сохраняется отдельно для каждого кадра; старые кадры по умолчанию открываются в авто. Ширина задаётся от 1 до 640, высота — от 1 до 641.
- «+1×1 ↘» ставит новую шахматку от нижнего правого угла выбранной, добавляет по столбцу и строке и выбирает её. Цвета клеток, прозрачность и фаза наследуются. Поле при необходимости растёт вправо, а в режиме автовысоты подстраивается снизу.
- Стрелки перемещают главную выделенную шахматку на клетку, Shift со стрелкой на 10. Шахматка с меньшим числом клеток всегда выше большей. Цветные квадраты идут от нижнего слоя к верхнему. «Вперёд» и «Назад» меняют порядок при равной площади. Добавление, удаление, скрытие и отмена до 40 изменений доступны в меню. Перемещение, копирование или изменение размеров за один жест занимает одну запись отмены.
- Положение, размеры, цвета, прозрачность, видимость, размер общего поля, выделение, цифры и режим наложения сохраняются для каждого кадра. Для обводок без сохранённого цвета выбираются разные оттенки.
- Счётчик выбранной шахматки показывает количество клеток/битов, нулей и единиц. Общая сумма считает клетки по всем шахматкам, с повтором на участках наложения.

- «XOR все» показывает 1 при нечётном числе единиц в одной позиции. «AND все» показывает 1, когда в этой позиции у каждой видимой шахматки стоит 1. Позиция за пределами шахматки даёт 0. Результат использует два цвета и непрозрачность верхней шахматки в этой позиции.
- «XOR RGB» и «AND RGB» считают биты отдельно для каждой палитры. В одну группу входят видимые шахматки, у которых совпадают и цвет 0, и цвет 1. Обводка и прозрачность не влияют на группировку. За пределами шахматки её бит равен 0. Цвета групп с результатом 1 накладываются в порядке слоёв. Если все группы дают 0, используется цвет нуля верхней шахматки.
- Режимы сразу реагируют на перемещение, инверсию, изменение цветов и видимости. Повторное нажатие возвращает обычное смешивание по прозрачности. Логические режимы показывают результат поверх исходных шахматок, которые остаются доступны для редактирования.

Код и изменения просмотрены. Проверки приложения и визуальная приёмка пользователем по AGENTS.md.


Размер клетки, ширина и высота поля, столбцы, строки и обе непрозрачности регулируются символьными ползунками. Все ползунки и обычные кнопки имеют ширину 120 px. Значение всегда справа в строке над дорожкой. Скобки меняют значение на один шаг, при удержании шаг повторяется. Двойной щелчок по числу или дорожке открывает ввод числа. С клавиатуры ввод открывается по Enter на ползунке.

## Кадры шахматок · v0.025

Для переключения откройте список «Кадр» над полем. Номер открытого кадра виден и рядом с заголовком «Шахматки». «Дубль» вставляет копию текущего кадра следом и сразу открывает её для редактирования. Положение и размеры шахматок, цвета, прозрачность, режим наложения и остальные настройки поля можно менять в каждом кадре отдельно. У каждого кадра своя история отмены в пределах открытой страницы. В группе «Порядок» кнопки «−1» и «+1» перемещают открытый кадр на одну позицию.

«Очистить» убирает все шахматки из текущего кадра одним действием с отменой. «Удалить» удаляет выбранный кадр, «Удалить все» удаляет всю последовательность. Обе команды удаления запрашивают подтверждение. Когда список пуст, кнопка «Создать» открывает новый пустой кадр. В последовательности может быть до 100 кадров.

Поле «мс» задаёт время показа текущего кадра, от 50 до 60 000 мс, по умолчанию 500 мс. «Плейъ» запускает циклическое воспроизведение с выбранного кадра. «Пауза» оставляет показанный кадр открытым для редактирования. Переключение вкладки Bit-Byte или уход со страницы также ставит воспроизведение на паузу.

Последовательность и выбранный кадр сохраняются в браузере в ключе `zerk_bit_chessboard_frames_v1`. При первом открытии прежнее поле из `zerk_bit_chessboards_v1` становится кадром 1. Поиск в диагоналях обрабатывает показанный кадр, а совпадения сохраняются в истории поиска под таблицей диагоналей.

## Диагонали итогового поля · v0.023

Под шахматками — таблица битов всего поля после текущего наложения. Каждый итоговый бит встречается ровно один раз. Диагональ с номером d+1 содержит клетки x+y=d: сначала верхний левый угол, затем следующие диагонали ↗ до нижнего правого угла. В строке x растёт, y убывает: слева снизу направо вверх. Все строки выровнены по центру, без пробелов между битами: например `1` / `00` / `111`. Для поля 3×2 порядок такой: `(0,0)` / `(0,1) (1,0)` / `(1,1) (2,0)` / `(2,1)` (координаты от нуля).

Пустые края каждой строки и пустые крайние диагонали убраны. Пропуски между битами внутри строки обозначены `·`; пустые диагонали между заполненными сохраняются пустыми строками. Это не биты 0. Шахматки за границей поля обрезаются, скрытые не участвуют. Таблица содержит до ширина + высота − 1 строк; широкая таблица прокручивается. Над ней указаны количества нулей, единиц и всех пустых клеток исходного поля.

Для XOR/AND всех шахматок и по палитрам, а также RGB+, таблица получает непосредственно тот же вычисленный бит, который рисует штатный обработчик поля. В обычном наложении полупрозрачных цветов единственного логического результата нет: таблица показывает бит верхней шахматки с ненулевой непрозрачностью данной клетки. Полностью прозрачная клетка пропускается. Цвет не переводится в бит порогом яркости; в логических режимах непрозрачность не меняет их прежнюю арифметику.

Таблица обновляется вместе с полем при переносе, растяжении, инверсии, изменении видимости, непрозрачности, режима и отмене. Отдельного сохранения не требует. Код/diff прочитаны; проверки приложения пользователем, автоматические прогоны не выполнялись.


## Поиск в диагоналях и найденные кадры · v0.024

В поле над диагоналями можно ввести несколько двоичных строк, по одной на строку, и нажать «Поиск». Сравниваются целые строки равной длины, без подстрок, разворота или инверсии. Пропуск `·` внутри диагонали не равен 0 и не удаляется ради совпадения. Совпавшая строка целиком выделяется жёлтым. Поиск обновляется вместе с полем; редактирование запроса ставит его на паузу до следующего «Поиск», «Стоп» сохраняет историю.

Разбор ввода используется прямо из Маятника: `MayatnikSequences.parse`, вместе с его служебным `mayatnik-ochki-method.js`. Ограничения: до 4096 строк и 2100000 битов, длина отдельной строки здесь до 640 (максимальная диагональ поля). Кнопка «Маятник» переносит сохранённые строки из ключа `mayatnik-sequences-v1` этого же браузера/домена и запускает поиск. Библиотека Маятника не изменяется. Настройки Bit-Byte отдельные: `zerk-bit-diagonal-search-v1`.

При совпадении автоматически сохраняется найденный кадр: PNG поля, настройки шахматок/наложения, запрос, номера исходных диагоналей и координаты совпавших клеток (x/y от нуля). Цветной растр фиксируется синхронно при находке, до асинхронного кодирования/хеширования/записи. PNG — собственный рисунок поля без пультов и рамок выделения; клетка до 16 px, сторона изображения до 2048 px. Для логических режимов используется уже рассчитанный canvas; обычные слои рисуются с теми же цветами, фазой, порядком и alpha. Звука в файлах нет.

Подключено штатное `MayatnikSearchFrameStore` без изменения его исходника, с отдельной базой IndexedDB `zerk-bit-byte-search-v1`/`frames`. Успех показывается после завершения транзакции. История переживает F5 и закрытие вкладки; это локальные данные браузера, не синхронизация между компьютерами. Существующие данные Маятника не затрагиваются. Повтор того же поля и запроса не создаёт ещё одну запись; выбор шахматки не меняет идентичность кадра. Все совпадения одного кадра записываются вместе. До 100 сохранённых/записываемых кадров; при лимите подсветка продолжается, новые снимки не сохраняются, старые не удаляются автоматически. При отказе хранилища или записи выводится явное сообщение.

В «Найденных кадрах» раскрывается снимок и список строк. PNG и JSON можно скачать, кадр можно удалить из браузерной истории. Удалённый кадр не восстанавливается автоматически в той же сессии поиска; новый явный запуск разрешает сохранить его снова. Во время записи отображается число ожидающих кадров — перед закрытием страницы дождитесь завершения.
