# Bit-Byte · v0.007

[Открыть](https://1001100.online/bit-byte/).

Вся страница разделена на четыре независимые вкладки:

| Вкладка | Поле | Значения | Подписи осей |
| --- | --- | --- | --- |
| Байт | 16 × 16 | 256 слов по 8 бит: `00000000`–`11111111` | HEX и 4 бита, например `9 (1001)` |
| Полубайт | 4 × 4 | 16 слов по 4 бита: `0000`–`1111` | HEX и 2 бита, от `0 (00)` до `3 (11)` |
| Четвертьбайт | 2 × 2 | 4 слова по 2 бита: `00`, `01`, `10`, `11` | HEX и 1 бит: `0 (0)`, `1 (1)` |
| Бит | 1 × 2 | 2 значения: `0`, `1` | Столбцы `0 (0)`, `1 (1)`; единственная строка `—` |

Строка задаёт старшую половину слова, столбец — младшую. У бита старшей части нет, поэтому одна строка и два столбца; вертикальный разворот отключён. Название вкладки «Четвертьбайт» выбрано пользователем; технический термин «дибит» указан в подсказке. У каждой вкладки свои исключения, расположение, отмена, ввод списка, сквозная и все таблицы статистики. Переключение вкладки не изменяет данные другой; прежний выбор байтов и полубайтов сохраняется.

- Слева — исключение байтов; справа — расположение поля.
- Горизонтальный и вертикальный развороты — две независимые половины одной кнопки стандартного размера: слева `↔ Стлб`, справа `↕ Стр`. Третьей команды разворота нет.
- «Столбцы» обращает горизонтальный порядок 0…F ↔ F…0 (0…3 ↔ 3…0 для полубайта).
- «Строки» обращает вертикальный порядок 0…F ↔ F…0 (0…3 ↔ 3…0 для полубайта).
- У четвертьбайта обе оси обращаются 0 ↔ 1; у бита — только столбцы.
- Обе включённые половины разворачивают обе оси: противоположные углы меняются местами (поворот расположения на 180°, не обмен строк со столбцами).
- «Исходно» возвращает обе оси к возрастающему порядку. Исключения сохраняются.
- Сквозная строка под полем склеивает оставшиеся байты по текущему расположению, слева направо и сверху вниз. Пробелы, разделители и дополнительные биты не вставляются. Ведущие нули каждого байта сохраняются. Переносы в текстовом поле только визуальные.
- При развороте меняется порядок байтов, а не порядок битов внутри каждого байта. Статистика строк/столбцов переставляется вместе с осями; итоги по выборке не меняются.
- Клавиши-стрелки следуют видимому направлению. Копирование сквозной строки выполняется только по кнопке; если буфер обмена недоступен, строка выделяется для Ctrl+C.

Исключения байтов сохраняются в прежнем `zerk_bit_byte_v1`, ориентация отдельно в `zerk_bit_byte_layout_v1`. У полубайтов ключи `zerk_bit_nibble_v1` и `zerk_bit_nibble_layout_v1`. Новым вкладкам выделены префиксы `zerk_bit_dibit` и `zerk_bit_bit` с теми же суффиксами. Последняя вкладка сохраняется в `zerk_bit_byte_active_tab_v1`. Отмена относится к последнему изменению исключений своей вкладки; история отмены и черновик списка живут до перезагрузки страницы. Вкладки доступны мышью и с клавиатуры (стрелки по кругу через все четыре, Home, End).

## Статистика сквозной

Кнопка «Кольцевать» включает и отключает замыкание последнего бита на первый для всех расчётов сквозной. По умолчанию включена; режим сохраняется раздельно: префикс своей вкладки и суффикс `_cyclic_v1`. Сам скопированный текст не получает повторного первого бита и дополнительных разделителей.

- Таблица серий показывает количество максимальных непрерывных серий каждой точной длины: одиночные 1/0, двойные, тройные и далее до наибольшей найденной длины. Например, `111` учитывается в длине 3, а не в длинах 1 и 2.
- При включённом кольце первая и последняя серии объединяются, когда состоят из одного бита. В линейном режиме они раздельные. Между байтами разрывов нет; исключённые байты удалены до расчёта.
- Для каждой длины отдельно показаны серии единиц и нулей, внизу — сумма серий и сумма содержащихся в них битов.
- Переходы 1→0 и 0→1 учитывают каждую соседнюю пару; последняя и первая позиции соседние только при включённом кольце. На двоичном кольце их количества равны; в линейной строке могут отличаться на один. Для однородной последовательности обе величины нулевые.
- Однородное кольцо считается одной серией длины полного обхода. Пустая последовательность даёт нулевые итоги без серий.
- Таблицы пересчитываются вместе со сквозной при исключении, восстановлении, отмене и смене расположения поля. Обычные суммы битов и байтов сохраняют тот же смысл: замыкание не добавляет битов.

## Все значения в сквозной

Таблица показывает все значения выбранного размера слова: 256, 16, 4 или 2, в том числе отсутствующие (с нулевыми количествами).

- Столбцы сдвигов: 0–7 для байта, 0–3 для полубайта, 0–1 для четвертьбайта, только 0 для бита. Сдвиг — позиция первого бита относительно начала сквозной. Внутри каждого столбца шаг равен длине слова: 8, 4, 2 или 1 бит.
- «Всего» складывает количества по сдвигам: это все перекрывающиеся окна с шагом один бит. Исключённое из поля значение может встречаться в окнах через границы соседних оставшихся слов.
- При включённом кольце учитываются окна через стык конца с началом; для непустой сквозной число окон равно числу битов `N`.
- Без кольца учитываются только полные окна внутри строки: `max(0, N−k+1)`, где `k` — длина слова. Для бита число окон равно `N` в обоих режимах. Нули не добавляются.
- Внизу — сумма по каждому сдвигу и общий итог. Все количества обновляются при изменении исключений, расположения и кольцевого режима своей вкладки.
