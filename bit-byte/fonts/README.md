# BitByte Operator

Локальное семейство **BitByte Operator**, начертания Regular (400) и Bold (700).

- `bitbyte-operator-regular.woff2` и `bitbyte-operator-bold.woff2` — веб-шрифты.
- Одноимённые `.ttf` — производные исходные файлы шрифта.
- `operator-digits.js` — `window.BitByteOperatorDigits`: самостоятельные SVG-пути оригинальных жирных цифр 0 и 1 для шахматных клеток. Координаты рассчитаны для клетки 1×1: центр по X — 0,5; верх — 0,20, низ — 0,85; ось Y вниз. Внешний шрифт для путей не нужен.

Латинские контуры и метрики взяты без изменения из `../../azbuk/fonts/8bitOperatorPlus-Regular.ttf` и `8bitOperatorPlus-Bold.ttf`. Автор оригинала — Grand Chaos Productions, 2009–2014. К каждому начертанию добавлены 66 русских букв А–Я, а–я, Ё и ё. Маски вычислены исходным алгоритмом АзъБукъ из `operator-masks.js` и `operator-cyrillic.js` (варианты `operator` и `operator-bold`), без новой интерпретации рисунка букв. Каждая заполненная клетка — квадрат 100 единиц; базовая линия учитывает `descend`. Боковой отступ и правый пробел взяты из H соответствующего оригинального начертания; ширина определяется маской. Широкие кириллические буквы сохраняют ширину своей маски.

Производное семейство переименовано, поскольку **8-bit Operator+** — Reserved Font Name. Оригинальное имя сохранено в указании происхождения. Шрифты, производные клеточные контуры, SVG-цифры и генератор распространяются по **SIL Open Font License 1.1**; полный текст и оригинальное уведомление об авторских правах — в `SIL Open Font License.txt`.

Воспроизведение из корня репозитория: установить Python-пакеты `fonttools` и `brotli`, обеспечить Node.js в PATH и выполнить `python bit-byte/fonts/build-fonts.py`. Генератор использует только перечисленные локальные исходники. Генерация файлов выполнена; браузерные, визуальные и автоматические проверки остаются пользователю.
