# Музыка и голоса · v0.001

Единый раздел Хаба: https://1001100.online/music/

Сверху — три собственных процедурных голоса с одинаковой фразой «ноль, один».
Плееры работают независимо, кнопка «По очереди» запускает A → B → C; «Стоп»
останавливает записи. Одновременно играет один плеер. При уходе со страницы звук
останавливается. Подробности сборки и ограничения сравнения — [voices/README.md](voices/README.md).

Ниже — каталог собственных аудио, видео и музыкальных инструментов. Поиск работает
по названию, описанию, рецепту и тегам; фильтры по разделу и типу материала сохраняются
локально. Сначала выводятся 12 карточек, «Показать ещё» добавляет следующие. Медиа
загружаются только по действию пользователя; автоматического воспроизведения нет.
У карточки плеер находится рядом с описанием создания и ссылками на исходный раздел.

`catalog.json` собирается `python music/build-catalog.py` из реестров и описаний
репозитория. Это сборка данных, а не загрузчик внешней музыки. Новые материалы нужно
включать в сборщик вместе с происхождением и рецептом. Сравнение голосов пересобирается
`python music/voices/build.py`. Изменения генераторов требуют пересборки и обновления
описаний. Норматив: [ЗВУК.md](../ЗВУК.md).

Интеграция Хаба — новая ссылка `music/` в исходном меню. Общие ключи сохранённых
раскладок не менялись. Кнопки используют grozd.css и общий алгоритм сокращения подписей.
При отсутствии JavaScript три WAV доступны через стандартные аудиоплееры;
инвентаризация доступна отдельной ссылкой.
