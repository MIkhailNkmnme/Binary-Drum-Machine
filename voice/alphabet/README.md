# Русский алфавит звуков

Это **31 отдельный звук**, а не произнесённые названия букв. «Б» здесь — короткий согласный, без добавленного «э»; «Й» — короткий `j` длительностью 80 мс, без слов «и краткое». У **Ъ и Ь нет собственного звука**: они отмечены в каталоге как немые; файлов с их названиями и фиктивных звуковых клипов нет.

Е, Ё, Ю, Я представлены изолированным начальным вариантом `й + е/о/у/а`. Внутри слова произношение зависит от позиции и соседей; эта таблица не моделирует все такие случаи. Смычные согласные намеренно короткие; отсутствие следующего гласного может затруднять их узнавание. Человеческое качество и разборчивость не заявлены.

В каждом наборе 31 отдельный WAV алфавита, 10 отдельных WAV цифр, `alphabet.wav` и `digits.wav`. Общая последовательность начинается с 0,20 с тишины; после каждого звука — 0,45 с. Ъ и Ь в последовательности не произносятся. В ZIP сохранена структура путей репозитория, поэтому ссылки и команда сборки остаются пригодны после распаковки.

## Зеркалиус: четыре форманты

Используется наш [браузерный движок](../engine.js), адаптированный из [генератора procedural-v1](../../mayatnik/sign-voice/generate_procedural_bank.py). Новые партитуры звуков находятся в `VoiceCatalog`; прежние 69 названий сохранены отдельно в `VoiceLegacyCatalog`. Исходные названия не подменяются за звуковой алфавит.

Источник вычисляется как сумма до 60 гармоник с весом `exp(-h/40)/h` и детерминированный шум xorshift32. Число гармоник ограничено по максимальной частоте голоса: `min(60, floor(0.43 Fs / (max(pitchStart,pitchEnd)+vibratoDepth)))`. Четыре резонатора работают параллельно. Для каждого `r = exp(-π B/Fs)`, `w = 2π F/Fs`; знаменатель `1 − 2r cos(w) z⁻¹ + r² z⁻²`, коэффициент усиления `(1−r) sqrt(1−2r cos(2w)+r²)`. Выходы суммируются с четырьмя весами.

Голос по умолчанию плавно идёт от 124 к 107 Гц, вибрато 1,8 Гц по глубине и 2,1 Гц по частоте. Начальное семя шума — `0x5A45524B`. Смычки, фрикация и дрожание задаются математическими огибающими. Переход формант — 30 мс с `t²(3−2t)`; коэффициенты обновляются через 32 отсчёта. DC-фильтр `y[n]=x[n]−x[n−1]+0.995 y[n−1]`, края сегментов 4/5 мс, край всей фразы 8 мс. Пик нормируется до 0,7 перед конечным затуханием. Полные параметры и фактические формы каждого сегмента сохранены в паспорте.

Результат 22050 Гц переведён в 44100 Гц линейной интерполяцией ×2 только для общего формата файлов. Высота и длительность не сдвигаются. Это новая адаптация и новые партитуры; побайтовое совпадение с прежним Python-банком не обещается.

## DeepSeek: исходный DSP + наш адаптер алфавита

Пользователь подтвердил авторство DeepSeek для [исходного formant_voice.py](../../tools/voice/formant_voice.py). **Этот файл не изменён.** Новый `build.py` использует его вычисляемый импульсный источник, детерминированный шум `numpy.random.default_rng(7)`, резонатор и огибающие. Никакой записи человека в них не загружается.

Для гласных сохраняются три параллельных резонатора исходника с весами `1, 0.6, 0.3`, полосами 90/110/160 Гц и его частотами. Остальные исходные ветки сохраняют его устройство: щелевые — фильтрованный шум; смычные и аффрикаты — затухающий шумовой выброс; носовые — два резонатора; дрожащий — модуляция 26 Гц; аппроксиманты — два резонатора. Высота импульсного источника идёт от 112 к 96 Гц заново внутри каждого озвученного сегмента. **Мы изменяем длительности через адаптер**, чтобы задать такие же короткие сегменты, как в нашем алфавите; это не исходный готовый алфавит DeepSeek.

В старой таблице нет Ж и Щ. Для полноты добавлены **наши**, явно записанные в новом сборщике рецепты:

- Ж: импульсный источник через 300/160 Гц с весом 0,30; шум через 2400/900 Гц с весом 1 и 3600/1200 Гц с весом 0,30. Пары чисел — частота/полоса.
- Щ: шум через 3200/700, 4800/1000, 6500/1300 Гц с весами 1, 0,50, 0,25; длительность 220 мс.

Эти добавления не приписываются DeepSeek. Е/Ё/Ю/Я собираются как короткий й + соответствующий гласный. Согласные не получают дополнительного «а» или «э».

Цифры в этом наборе заново вычисляются штатным `speak_word()` по словам от «ноль» до «девять». Сохраняются ограничения старого движка: мягкий знак удаляется, я заменяется на а; полноценной контекстной мягкости нет. Некоторые звонкие/глухие смычные в исходном алгоритме различаются слабо. Разборчивость не проверялась.

## Сравнение и происхождение

Файлы обоих наборов — моно PCM16, 44100 Гц, целевой пик отдельного клипа 0,7. Совпадение пиков не означает одинаковую воспринимаемую громкость. Высота, тембр и устройство согласных различаются. Для алфавита заданы одинаковые длительности сегментов, однако округление отсчётов в движках немного отличается. Для цифр сохранены их собственные длительности. Музыка, эффект комнаты, изменение высоты и растяжение времени не добавлены.

Старый телефонный робот умеет только три заданных слова — zero, one, zerkalius. Здесь он **не представлен как третий полный алфавит**. Его прежний короткий пример доступен отдельно в [сравнении трёх голосов](../../music/index.html).

Все WAV заново вычисляются из исходников и параметров; существующие WAV/MP3, человеческий голос, микрофон, TTS, системные голоса, обученные веса, сетевые звуковые входы не используются. Архив содержит исходники и нормализованные SHA-256 (UTF-8, LF); паспорт содержит хеши выходных WAV и версии Python, NumPy, Node.js.

## Воспроизведение сборки

Из корня репозитория или распакованного архива:

```text
python voice/alphabet/build.py --node node
```

Нужны Python с NumPy и Node.js. Можно передать полный путь к Node через `--node`. Команда производит WAV, JSON и ZIP; исходные движки не редактирует.

Выполнено только производство артефактов и запись метаданных. Автотесты, синтаксические проверки, браузер, воспроизведение и слуховая приёмка не запускались. Качество звучания оценивает пользователь.
