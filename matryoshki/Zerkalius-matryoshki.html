Матрёшки · первый опыт

Маятник строится по очереди: вершина, −1, +1, −2, +2… Исходное поле остаётся в своих координатах. Здесь показывается конус первой вершины, обе битовые решётки.

Свёртка начинается с оси. В строке r бит на расстоянии d слева включается после такта 2(r+d), справа — после 2(r+d)+1. Это гарантированный срок: будущие конусы уже не достанут до клетки. Некоторые биты могут остыть раньше — эта версия следует строгому ритму.

Слои ограничивают глубину свёртки: 1, 2, 4, 8… столбцов с каждой стороны. «Вся готовая» показывает всю свёртку, разрешённую текущим тактом. Это уровни одного исходного поля, а не независимые копии генератора. Частично свёрнутые строки содержат XOR на оси; полностью свёрнутые строки раскрываются внутри следующим уровнем. Исходники доступны по нажатию.

Полностью свёрнутые верхние строки уходят во внутреннюю матрёшку с предыдущей степенью свёртки. Оставшиеся строки поднимаются к вершине, поэтому столба над фигурой нет. Цветные контуры отделяют уровни; внутренние рисунки уменьшены, но их исходные адреса сохраняются. Если весь участок свернулся, показывается его содержимое. «Рядом» раскрывает выбранный и предыдущие уровни для сравнения. Колесо — масштаб, перетаскивание — сдвиг. «Вписать» возвращает общий вид.

Страницу можно открывать с диска: без фонового потока расчёт выполняется короткими порциями с паузами для интерфейса. На сайте используется Worker; при его отказе включается тот же локальный расчёт.

«Рост» увеличивает глубину участка по мере продвижения. Новый участок пересчитывается тем же ядром с начала, сохраняя прежние верхние строки. При нехватке памяти рост остановится с сообщением; бесконечность относится к модели, не к объёму памяти браузера.
