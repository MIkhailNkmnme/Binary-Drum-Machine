- 4 новые композиции: «Импульс восьми ветров», «Медная орбита», «Письмо двух рек», «Тонкий лёд», 77,8–83,4 секунды.
- 4 версии на звонок, 21,8–25,3 секунды, MP3 и M4R.
- 20 уведомлений, 1,25–3,6 секунды, MP3 и WAV. Это вырезки из четырёх новых и двух прежних композиций, с таймкодами и фейдами.
- 12 обоев 1440 × 3200: шесть цветных и шесть чёрно-белых. Есть PNG, превью 360 × 800 и редактируемые SVG; надписей и часов на самих файлах нет.
- Четыре ZIP: музыка, уведомления, обои, весь набор. Полный набор — 31,4 МиБ.

Страница статическая; встроенные аудиоплееры и скачивание работают без JavaScript. Небольшой `page.js` останавливает предыдущий плеер при запуске следующего. Файлы загружаются по выбору посетителя; изображения в галереях отложены до прокрутки.

## Связь с Синтезом

Исходные движки и прежние две композиции не менялись. Сопровождение новых треков использует `frameEvents()` и реальные последовательности полей Маятника; ведущие мотивы и форма сочинены отдельно. Подробности, ноты, состояния поля и MIDI: [музыкальное описание](music/README-music.md), [реестр](music.json).

Обои продолжают code-native графику Маятникового атласа. Поле вычисляется прежним движком; кольцо, линза, розетка, ленты и конус — художественные проекции клеточной геометрии. Это не новые физические законы. Параметры и происхождение каждого варианта: [wallpapers.json](wallpapers.json).

## Сборка

Из корня репозитория нужны Node.js, Python 3, FFmpeg/ffprobe; для графики — пакет `sharp`, доступный Node.js (можно через `NODE_PATH`).

```sh
node issledovanie/phone-theme/music/build-music.cjs
node issledovanie/phone-theme/music/check-music.cjs
node issledovanie/phone-theme/art/build-wallpapers.cjs
python issledovanie/phone-theme/build-page.py
python issledovanie/phone-theme/build-downloads.py
```

Генераторы музыки и графики независимы. `build-page.py` читает оба JSON, а `build-downloads.py` собирает ZIP и сверяет каждую запись с исходным файлом. Промежуточные WAV не нужны сайту; нотные данные сохранены в Git.

## Фактическая проверка

- [Аудио](music/audio-checks.json): декодированы 52/52 файла; клиппинг 0. Наибольший пик после пересчёта в 176,4 кГц −3,047 dBFS. Все 20 WAV побайтно совпали с независимым повторным извлечением PCM из указанных MP3.
- Графика: 12 полноразмерных PNG и 12 миниатюр имеют заявленные размеры; у всех шести чёрно-белых PNG каналы R/G/B равны. Визуально просмотрен [контактный лист](art/contact-sheet.jpg).
- [Страница](qa/browser.json): Chrome, ширины 320/390/768/1440 CSS px, без горизонтальной прокрутки. Наблюдались продвижение трека, остановка предыдущего при запуске другого, завершение двухсекундного уведомления и раскрытие версии на звонок. [Телефонная раскладка](qa/mobile.png), [широкая](qa/desktop.png).
- [Файлы](qa/files.json): 191 локальная ссылка/медиассылка, отсутствующих целей нет; ID уникальны. Архив уведомлений скачан через браузер и совпал с подготовленным ZIP.
- [Архивы](downloads/manifest.json): CRC и содержимое каждой записи сверены с исходниками.

Установка на физические Android/iPhone и субъективная оценка всей музыки не выполнялись. Технические проверки не заменяют музыкальный вкус пользователя. Краткие инструкции установки на странице опираются на [Google](https://support.google.com/android/answer/9082609?hl=ru) и [Apple](https://support.apple.com/ru-ru/120692).
