## Связь с Синтезом

Исходные движки и прежние две композиции не менялись. Сопровождение новых треков использует `frameEvents()` и реальные последовательности полей Маятника; ведущие мотивы и форма сочинены отдельно. Подробности, ноты, состояния поля и MIDI: [музыкальное описание](music/README-music.md), [реестр](music.json).

Обои продолжают code-native графику Маятникового атласа. Поле вычисляется прежним движком; кольцо, линза, розетка, ленты и конус — художественные проекции клеточной геометрии. Это не новые физические законы. Параметры и происхождение каждого варианта: [wallpapers.json](wallpapers.json).

## Сборка

Из корня репозитория нужны Node.js, Python 3, FFmpeg/ffprobe; для графики — пакет `sharp`, доступный Node.js (можно через `NODE_PATH`).

```sh
node issledovanie/phone-theme/music/build-music.cjs
node issledovanie/phone-theme/music/check-music.cjs
node issledovanie/phone-theme/music/build-sms.cjs
node issledovanie/phone-theme/music/check-sms.cjs
node issledovanie/phone-theme/art/build-wallpapers.cjs
node issledovanie/phone-theme/art/build-geometric-wallpapers.cjs
python issledovanie/phone-theme/merge-wallpapers.py
python issledovanie/phone-theme/build-page.py
python issledovanie/phone-theme/build-downloads.py
```

Генераторы музыки и графики независимы. `build-page.py` читает оба JSON, а `build-downloads.py` собирает ZIP и сверяет каждую запись с исходным файлом. Промежуточные WAV не нужны сайту; нотные данные сохранены в Git.

Страница показывает пояснения к каждой теме и изображению.

- Аниматрицы: состояния действующего движка проекта; исходная сцена и шаг указаны в рецептах.
