Открываем холст…

Колесо — масштаб у курсора; Рука / пробел / средняя кнопка — перемещение. Кисть — существующий бит; Фигура — все её биты; + Бит — клетка внутри квадрата фигуры; Ластик — убрать бит. Ctrl+Z / Ctrl+Shift+Z — отмена / повтор. Открыть — SVG раскладки или JSON; SVG сохраняет рисунок, JSON — редактируемый проект. Центр сочетаний остаётся нейтральным. Для своего xor-256-triangle.svg нажмите «Открыть».
