# Четыре глифа Kraftwerk · первые 22 секунды

Версия 0.002 · DRAFT. Четыре фигуры показаны в 17 устойчивых эпизодах и двух дополнительных опорных кадрах (один смешанный набор подтверждён). Интервалы смены устойчивой формы дают оценку около 1,25 секунды. Красный слой меняет яркость и внутри устойчивых эпизодов. Правило выбора очередной формы остаётся открытым.

[Страница исследования](index.html) · [Исследования Зеркалиуса](../Zerkalius-issledovanie.html)

## Источник и границы наблюдения

Источник — [Kraftwerk Koncert 2026, Veszprém](https://www.youtube.com/watch?v=BNYdUn7gmmI). MP4 собран из 568 экранных кадров по меткам времени воспроизведения. Получившийся фрагмент длится 22 секунды и не содержит аудио. Движение камеры и монтажные склейки сохранены. Соответствие видеокадров снимкам и погрешность выборки записаны в glyph22-clip-provenance.json.

Трассировка в PNG и SVG передаёт различимые жёлтые и красные линии. Свечение, сжатие и удаление камеры могут скрывать мелкие детали. Из записи удалось оценить темп смены формы. Точные клеточные маски, авторский алгоритм и источник изменений красного слоя остаются неизвестными. В glyph22-findings.json сохранены интервалы, наблюдения и имена опорных кадров.

## Воспроизведение анализа

Для трассировки из опубликованных опорных кадров установите Pillow, NumPy и opencv-python-headless. Выполняйте команды из папки исследования.

~~~sh
python -m pip install Pillow numpy opencv-python-headless
python drafts/analysis/plate.py --output /path/to/scratch
python drafts/analysis/register.py
~~~

Для надписей скрипт использует локально доступные шрифты. Аргумент --font-dir позволяет указать папку с файлами Georgia, Segoe UI и Consolas, использованными в итоговом листе. С этими шрифтами первые 18 рядов воспроизведены пиксель в пиксель. В последнем ряду около края меняются 3197 пикселей из 5 488 640: чёрная маска влияет на трассировку в увеличенном кадре. Состав набора кадров в новом JSON отличается от исходного полного ряда.

Скопируйте MP4 и glyph22-clip-provenance.json в папку результатов трассировки. Команда python drafts/analysis/build-viewer.py --output /path/to/scratch соберёт из этих материалов автономный просмотрщик. Скрипты build-clip.py и colour.py сохранены для проверки метода. Для повторной сборки видео нужен FFmpeg и полный ряд снимков с samples.json, для расчёта цветовой кривой также нужны дополнительные кадры. Полный ряд в репозиторий не включён.
