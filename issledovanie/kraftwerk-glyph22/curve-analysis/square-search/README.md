## Модель

Из исходного графа берутся только концы принятых рёбер; служебные изолированные узлы не входят в цель. Координаты активных узлов умножаются на 2, середина каждого единичного ребра добавляет ещё одну белую клетку. Это выбранный квадратный растр по оцифрованной осевой схеме, а не точные пиксели фотографии.

Чётные позиции маршрута рисуют белый заполненный квадрат, нечётные не рисуют ничего. Пустое посещение целевой клетки разрешено и не стирает её. Каждый переход — соседняя клетка в одном из 8 направлений. Запрещён непосредственно H→V и V→H; ограничение угла направленного поворота до45° не вводилось. Каждая целевая клетка рисуется белым ровно один раз, никакая лишняя клетка не рисуется. Каждый неориентированный геометрический отрезок проходится максимум один раз; точечные пересечения допускаются.

Для найденного маршрута OR и XOR дают один и тот же целевой растр: на каждую целевую клетку приходится ровно одна единица. Белые клетки могут дополнительно посещаться пустыми шагами.

## Математическое сведение

Между соседними белыми посещениями ровно два шага. Поэтому их координаты отличаются не более чем на2 по каждой оси. Разность (±1,±1) запрещена: двухшаговая связка была бы только H,V или V,H. Для остальных ненулевых смещений в этом квадрате существует связка с первым диагональным шагом; она согласуется с любым входящим классом направления.

Так строится конечный граф потенциальной последовательности белых клеток. Ищется гамильтонов путь; затем выбираются промежуточные пустые клетки с проверкой переходов направлений и неповторения геометрических сегментов. Поиск использует проверку связности остатка, необходимое ограничение числа вершин степени1, эвристику остаточной степени и ограниченные перезапуски. Неудача такого ограниченного поиска не доказывает отсутствие пути.

При N целевых клетках найденные пути имеют 2N−1 позиций, то есть 2N−2 перехода. Это минимум при старте и финише на1: для N белых записей нужны как минимум N−1 промежуточных нулей.

## Два строгих барьера

Для11/1 граф достижимости белых клеток распадается на89+3 клетки; маленькая компонента — (18,4),(18,5),(18,6). Для11/2 —95+3; маленькая компонента — (18,6),(18,7),(18,8). Это отделённые вертикальные кусочки у правого края. Последовательность белых посещений не может перейти между компонентами без белой записи вне цели. Связность проверена непосредственно, компоненты сохранены в `paintComponents`.

Оба исходных графа имеют низкую уверенность оцифровки: шаг решётки на съёмке меньше5,5 пикселя. Вывод относится к текущему растру. Он не запрещает другой разбор фотографии, другое разрешение или модель с временными лишними белыми клетками и последующим стиранием.

## Воспроизведение

Стандартный Python, без сторонних пакетов:

```sh
python square-search/find-routes.py --source graphs.json --out-dir square-search/reproduced --seconds 2
python square-search/retry-batch.py --source graphs.json --out-dir square-search/reproduced --seconds 8 --workers 4
python square-search/reuse-isometries.py --routes square-search/reproduced
```

Время вычисления ограничено, поэтому число найденных путей при повторном запуске может отличаться. Имеющиеся положительные свидетели проверяются независимо от времени поиска. `sourceSha256` в итоговом `batch.json` связывает результат с исходными графами. Скрипты и данные не задают модель генератора оригинального видео.
