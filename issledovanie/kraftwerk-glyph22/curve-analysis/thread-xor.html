Белая нить и XOR

13 ноября 2026 · 0.001 · исследовательский черновик

Белая нить идёт по замкнутому маршруту третьего глифа из кадра 06 (около 6,9 с). Маршрут проходит по всем 48 рёбрам восстановленного контура один раз за круг. Две точки пересечения встречаются по два раза за круг.

XOR переключает цвет при каждом проходе. Нечётное число проходов даёт белый, чётное — чёрный. Для узла считаем каждый выход из него по очередному ребру. Конец круга совпадает с началом и отдельно не прибавляется.

Точки J1 и J2 в модели имеют нулевой размер. В рисунке чёрные точки увеличены, чтобы показать их поверх белых рёбер. Во время незаконченного круга точка может быть белой после первого посещения.

Две одинаковые нити, уложенные по одному маршруту, дают ту же чётность, что два полных прохода одной нити. Это опыт с графом восстановленного контура. Данные проверки.
