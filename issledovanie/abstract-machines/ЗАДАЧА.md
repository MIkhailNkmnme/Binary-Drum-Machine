# МАЯ-683 · Синтез звука через биты

Статус: **план, не реализовано.** Разбор-основание — `README.md` рядом.

## Запрос

Сделать в Зеркалиусе синтез звука через биты: чтобы бит управлял не только тем, когда звучит голос, но и самой формой волны. Образец — канал Abstract Machines, где «every sound is a written function»: число из битов задаёт частоту, биты — амплитуды партиал, формула — огибающую.

## Что уже есть

`Binary-Drum-Machine/mayatnik/mayatnik-synthesis-music.js` (518 строк) — рабочий музыкальный движок:

- `frameEvents(frame, options)` — кадр `{ tick, width, height, a, b, result }` → события `{ beat, duration, midi, velocity, voice, pan }`. Биты влияют на статистику: `ones`, четыре полосы `bands`, `overlap`, `transitions`; по ним меняются велосити хэта, питч лида, панорама и плотность.
- `renderVoice(voice, midi, duration, rate)` — посимвольный PCM для семи голосов (`kick`, `snare`, `hat`, `bass`, `lead`, `piano`, `strings`); формулы жёстко зашиты, биты в них не участвуют.
- `renderWav`, `exportMidi`, `createPlayer` — офлайн-рендер WAV, экспорт MIDI, живое воспроизведение через Web Audio.
- `mayatnik-synthesis-music.test.cjs` — 218 строк проверок: нормализация настроек, повторяемость мотивов, влияние битовых полос, байты MIDI, заголовок WAV.

Чего нет: бит не является параметром синтеза. Битовая строка не превращается в число, число — в частоту, а биты — в амплитуды партиал. Именно этот шаг и добавляем.

## Что делаем

Новый модуль `mayatnik-bit-synthesis.js` (рядом, UMD как у соседей: `module.exports` + `globalThis.MayatnikBitSynthesis`), существующий движок не переписываем — только расширяем точкой входа.

### 1. Ядро: биты → число → высота

- `bitsToNumber(bits)` — `n = Σ bⱼ2ʲ`, порядок фиксирован и задокументирован: бит 0 — младший, строка растёт снизу вверх (как в ролике «Does counting have a beat?», где «a row = a bit»). Без этой договорённости питч не воспроизводим.
- `numberToMidi(n, { root, scale, span })` — число → ступень лада → MIDI; для 0…63 обязаны получиться 64 различимые высоты.
- `rowToBits(frame, { row, column, mode })` — взять строку, столбец или `result` целиком; пустые/битые кадры → `[]` (как `frameEvents` сейчас).

### 2. Тембры: биты → форма волны

- `bitsToPartials(bits, { base, tilt })` — включённые биты задают партиалы: `a_k = b_k · tilt^k`. Один бит — одна синусоида, `k`-й партиал — `k·f₀`.
- `renderBitVoice(bits, { f0, tau, gain, rate, partials })` — `x(t) = Σ_k a_k sin(2π k f₀ t) · e^{−t/τ}`. Партиалы выше `0,45·rate` отбрасывать (антиалиасинг), `tau` ограничить 0,004…2 с, `f0` — 20…2000 Гц.
- Три готовых тембра по образцу разбора:
  - `harmonic` — ряд одного тона (как «How the machines make sound»: 65,9 · 130,5 · 196,5 · 261 · 329 Гц);
  - `shepard` — `s(t) = Σ_k w(k+u) sin(2π f_k t)` с косинусной весовой функцией по логарифмической оси частот;
  - `click` — бит как огибающая: `e^{−t/τ}` с шумом, частота не нужна.

### 3. Мост к существующему движку

- В `frameEvents` добавить опцию `synth: 'voices' | 'bits'` (по умолчанию `voices`, чтобы старые тесты и звук не менялись). При `bits` события собирает `bitFrameEvents` из нового модуля.
- `cleanEvents` и `renderWav` переиспользовать как есть; новый голос описывается записью в `VOICES` с полем `bits: true`.
- Панель (`mayatnik-music-panel.js`): переключатель «Биты → звук» и **таблица параметров** в духе образца — `n`, двоичная запись, `f₀`, `τ`, число партиал, `g`. Значения обновляются от кадра, без перерисовки раскладки (правило КН06 и стандарт кнопок не трогаем).

### 4. Экспорт

Не добавлять новый формат: `renderWav(events, options)` и `exportMidi(events, options)` уже есть. Проверить, что новый голос проходит через оба.

## Критерии приёмки

1. Для всех `n` от 0 до 63 `numberToMidi` даёт 64 различные высоты; повторный вызов при тех же настройках — тот же результат (детерминизм, тест на хеш массива).
2. Спектр `renderBitVoice`: число пиков равно числу включённых битов (`popcount`) в пределах допуска ±1; частоты партиал совпадают с `k·f₀` с точностью 1 Гц. Проверять ДПФ на выбранных бинах внутри `node --test`, без внешних зависимостей.
3. Пустая строка битов и битый кадр дают тишину/`[]`, а не исключение.
4. WAV: 44,1 кГц, стерео, длина соответствует событиям, семплы по модулю ниже 0,99 (нет клиппинга выше soft-clip).
5. Старые проверки не ломаются: `node --test Binary-Drum-Machine/mayatnik/mayatnik-synthesis-music.test.cjs` зелёный, звук режима `voices` побайтно совпадает с текущим (хеш WAV до/после).
6. Таблица параметров в панели показывает `n` и его двоичную запись, `f₀`, `τ`, число партиал; при смене кадра значения меняются, раскладка не сдвигается.
7. Живой режим: 32 партиала на кадр не вызывают пропусков — ключ кэша включает битовую строку, размер кэша ограничен, как сейчас (160 записей).

## Порядок работ

1. **bit_synthesis_core** — `bitsToNumber`, `numberToMidi`, `rowToBits`, `bitsToPartials`, `renderBitVoice`, антиалиасинг и ограничители. Сложность средняя, чистые функции, без DOM.
2. **bit_synthesis_voices** — три тембра, сведение с `VOICES`, `cleanEvents`, `renderWav`, `exportMidi`. Сложность средняя.
3. **bit_synthesis_ui** — переключатель и таблица параметров в панели, без сдвига раскладки. Сложность обычная.
4. **review** — независимая проверка критериев 1–7, спектральный тест и сверка хеша старого WAV.

Оценка сложности: **высокая** (новый слой синтеза + связка с готовым движком и панелью). Root — интеграция, документы и публикация.

## Риски и неопределённости

- **Порядок битов.** Если младший бит выбрать сверху, все высоты инвертируются. Договорённость фиксируется в шапке модуля и в тесте, иначе результат не воспроизводим между сессиями.
- **Стоимость живого рендера.** Параметры меняются от кадра к кадру, кэш по ключу будет промахиваться чаще, чем сейчас. Ограничение: 32 партиала, кэш 160 записей, при промахе — только смена `f₀`, остальные партиалы переиспользуются.
- **Найквист.** 32 партиала от 55 Гц дают 1760 Гц — безопасно; от 200 Гц уже 6400 Гц, а при 800 Гц верх выходит за предел. Отсюда жёсткое правило `k·f₀ < 0,45·rate`.
- **Shepard-тон** требует логарифмической оси частот и весовой функции; при малом числе партиал эффект не читается. Минимум — 8 октавных слоёв, это дороже остальных тембров.
- Расхождение с образцом: у Abstract Machines всё считает один пайплайн (картинка и звук из одних функций). У нас биты считает поле Маятника, поэтому таблица параметров — это отображение, а не первоисточник. Расхождение осознанное: встраиваемся в существующую архитектуру, а не переписываем её.
