# АвториФматор · 0.001

Последняя редакция в `history.json` задаёт текущую задачу, порядок разделов и следующий шаг. При открытии новой редакции команда добавляет запись и фиксирует коммит, на котором осталась предыдущая. Страница показывает прежние редакции со ссылками на материалы и снимки Git.

Чтобы сменить курс, опубликуйте намерение в `ПЛАНЫ.md` и закоммитьте материалы текущего курса. Подготовьте JSON с номером текущей редакции в `previous`, новым заголовком, причиной, следующим шагом и разделами в нужном порядке. Например, если в истории последняя редакция 2:

```json
{
  "previous": 2,
  "title": "Ритм и визуальные ряды",
  "reason": "Следующая задача начинается с музыкальных опытов.",
  "next": "Выбрать один опыт для дальнейшей работы.",
  "sections": [
    {
      "title": "В работе",
      "links": [
        { "title": "Маятники, мелодии и картины", "path": "issledovanie/pendulum-music/index.html" }
      ]
    }
  ]
}
```

Запустите из корня репозитория в PowerShell:

```powershell
cmd /c 'node issledovanie\autorifmator\course.cjs advance < course-draft.json'
```

В Bash та же команда запускается как `node issledovanie/autorifmator/course.cjs advance < course-draft.json`. Входной файл сохраняйте в UTF-8. Затем закоммитьте `issledovanie/autorifmator/history.json` и отправьте в `main`. Для возврата к прежнему направлению возьмите его порядок разделов в новую редакцию с объяснением причины возврата.
