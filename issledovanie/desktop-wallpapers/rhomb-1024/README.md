# Ромбовые обои на 1024 строки

Статичная коллекция из 300 PNG для рабочего стола. Каждая из 30 серий содержит десять разных кадров в палитрах из [цветной коллекции Журнала картинок](../../image-journal/rhomb-collection/). Исходная высота всех полей составляет 1024 строки. Готовые изображения имеют размер 3840 × 2160, соотношение сторон 16:9.

Построения отрисованы с сохранением пропорций внутри широкого кадра. Свободное место вокруг фигуры заполняет фон выбранной палитры. В `recipes.json` указаны размеры исходных полей, способы накопления и движения, номера кадров, палитры и SHA-256 исходных PNG. WebP используются для предпросмотра.

Для повторной сборки из корня репозитория выполните `node tools/mayatnik-journal/build-rhomb-wallpapers.cjs`. Нужны Node.js 22 или новее и доступный модуль `sharp`.
