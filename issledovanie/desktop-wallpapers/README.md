# Живые обои для компьютера · v0.001

[Коллекция](https://1001100.online/issledovanie/desktop-wallpapers/). Девять обоев 3840 × 2160 в соотношении 16:9. Каждый из них включает восьмисекундный зацикленный MP4 без аудиодорожки, статичный PNG того же разрешения и компактное превью WebP.

- Маятники берут состояния из `mayatnik-phone-scenes.js` и `mayatnik-synthesis-pendulums.js`. Цвет клетки отражает состояние двух полей или след. Исходные рецепты указаны в реестре.
- Зеркалиусы строят строки по XOR соседей с нулевыми краями, по правилу `zzPascalNext` из `zazerkalius/zz-core.js`. Экспозиция, расположение конусов и выбранные начальные строки сделаны для этого выпуска.
- Ромбы используют реальные поля правила 90 из движка сцен Маятника. Верхняя и нижняя половины отражены вдоль центральной линии, а положения повторов различаются по работе.

Кадры вычисляются от исходных клеточных полей и рисуются сразу в широком кадре. Положение поля, сдвиг и подсветка идут по периодическим функциям, поэтому следующая фаза после последнего кадра — начальная. Промежуточный ряд содержит 12 рассчитанных кадров в секунду, MP4 экспортируется в 24 кадрах в секунду.

## Сборка

Нужны Node.js, `sharp` (можно через `NODE_PATH`) и FFmpeg с libx264. Из корня репозитория выполните `node issledovanie/desktop-wallpapers/build.cjs`. Добавьте `--resume`, чтобы сверить хеши и повторно использовать завершённые файлы текущего сборщика. Реестр `manifest.json` хранит исходные рецепты, размер и хеш каждого результата.

Галерея читает MP4 только при воспроизведении. PNG и MP4 скачиваются отдельно, просмотр и загрузка доступны без JavaScript. Проверки страницы и визуальная приёмка остаются пользователю.

Проверены заголовки девяти MP4 и девяти PNG. Ролики содержат один поток H.264 3840 × 2160, 192 кадра при 24 кадрах в секунду. Хеши всех 27 медиафайлов совпали с реестром.
