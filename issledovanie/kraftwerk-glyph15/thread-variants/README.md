# Толщина, повтор и пустота

ИСС-108 · 2026-11-14 · [Страница](https://1001100.online/issledovanie/kraftwerk-glyph15/thread-variants/).

Проверены уточнения пользователя: второй проход разрешён только там, где утолщение видно; обратный вариант — толстое только один раз, тонкое допускает второй; отдельно нить 1–0 из заполненных квадратов. Считаются все исходные осевые отрезки, включая внутренние перекладины. Пересечения считаются общими узлами. Запрет непосредственного перехода H↔V относится к модели квадратной нити, не к двум моделям обхода осевого графа.

| Модель | Разных осевых форм | Мест в 15 строках |
|---|---:|---:|
| Без повторения ребра | 13/45 | 17/60 |
| A: тонкие ровно1, толстые1или2 | 36/45 | 49/60 |
| B: толстые ровно1, тонкие1или2 | 16/45 | 21/60 |
| Все толстые обязательно2, тонкие1 | 0/45 | 0/60 |
| Все тонкие обязательно2, толстые1 | 0/45 | 0/60 |

По A невозможны только9 несвязных геометрий (11 мест). По B дополнительно мешает чётность в компонентах разрешённых повторов. Явные маршруты A/B сохранены в `thickness.json`, поля `cases[].variants.*.route`. Они не обязаны быть кратчайшими. Каждый присутствующий отрезок покрыт один или два раза, третий проход запрещён. Всего70 положительных свидетелей.

Толщина здесь является меткой допустимости, а не автоматически получаемым эффектом. Точное наложение штрихов при OR не удваивает их геометрическую ширину, а при XOR гасит совпавшие пиксели. Смещённые нити и отрисовка ширины по кратности потребовали бы другой модели. Следовательно, успешный обход A не означает, что толщина исходного изображения воспроизведена количеством наложений.

## Измерение

Взяты3 уверенных снимка каждого эпизода,11 поперечных сечений центральных30–70% длины каждого отрезка. Использован FWHM нормированной темноты красного/зелёного относительно местного фона. Отдельные углы и узлы не измеряются как ширина линии. Получены3188 значений «ребро в эпизоде/месте»:612 тонких и2576 толстых. Основные классы около3,48 и5,99px; есть редкие более широкие участки.

Между всеми сечениями пустой интервал4,1408–5,58px. Порог4,7px лежит внутри него. Нет разногласий классов ни между тремя снимками, ни между сечениями. `thresholdSensitivity` сохраняет результат для разных порогов; порог не подбирался по успешности обхода.

G19 в строках3/12 меняет толщину одного ребра V0,5: около3,5749→5,8796px. Поэтому получены45 осевых геометрий, но46 сочетаний геометрии и маски толщины. В обоих случаях итог A/B одинаков. `source-thickness-change.png` показывает исходные пиксели с увеличением×6. Это уточняет прежнее утверждение о повторе строк: осевые рёбра повторяются, вся обводка — нет.

## Точный критерий A/B

Пусть O — множество нечётных вершин исходного связного графа, D — подмножество разрешённых для удвоения рёбер. Повтор меняет чётность в концах D. Для одного открытого/замкнутого пути после изменения должны остаться2 или0 нечётных узлов.

В каждой компоненте графа разрешённых повторов граница D имеет чётную мощность. Поэтому число таких компонент, содержащих нечётное число вершин O, должно быть0 или2. Это также достаточно: выбираем конечные точки в нечётных компонентах, а нужное множество D строим по остовным деревьям. Изолированные вершины учитываются как отдельные компоненты. Несвязность исходного графа отдельно запрещает единую нить. Критерий сверен полным перебором2186 малых задач; все70 построенных маршрутов проверены по каждому проходу.

## Нить1–0

`dashed.json` содержит45 целей:41 найденный и независимо проверенный маршрут,4 случая `time_limit` (G13,G21,G33,G55). Лимиты4,12 и40 секунд на нерешённую форму не доказывают невозможность. Сохранён промежуточный отчёт `dashed-after-12s.json`. Часть маршрутов перенесена из прежнего исследования только при точном совпадении целевого растра с допустимой изометрией; каждый перенос проверен заново.

Цель строится на прежнем половинном шаге: концы осевых рёбер×2 и середины рёбер становятся заполненными квадратами. Это конкретная растеризация клеточного глифа, а не исходные пиксели видео и не переменная толщина.

Чётная позиция маршрута рисует1, нечётная не рисует и не стирает. Каждый шаг — одна соседняя клетка в8 направлениях; H→V/V→H непосредственно запрещены, а отдельное ограничение поворота до45° не вводится. Пустой шаг может попасть на целевую белую клетку. Белые клетки не повторяются, геометрические отрезки пути не повторяются, точечные пересечения разрешены. Поэтому конечный OR и XOR совпадают с целью. При N белых клетках каждый найденный маршрут имеет2N−1 позиций, что достигает нижней границы для заданного чередования и окраски каждой цели ровно один раз.

## Файлы и повторение

- `thickness.py/json`: измерения, распределения, разрешённые/фактические повторы, критерий и70 маршрутов.
- `thickness-check.json`: устойчивость и полный перебор малых задач.
- `dashed.py/json`: поиск/перенос путей; используются прежние `../../kraftwerk-glyph22/curve-analysis/square-search/find-routes.py` и независимый `square-thread-check.py`.
- `check-variants.py`, `independent-check.json`: отдельная проверка всех маршрутов, целей и сертификатов невозможности A/B; код решателей не импортируется.
- `build-report.py`, `plates/`:60 сравнений исходной обводки/A/B и45 листов квадратной нити, каждый с номерами позиций и развёрнутой последовательностью.
- Все исходные кадры и `analysis.json` находятся в родительском исследовании. Пользовательские данные и полный экран браузера не публикуются.

Python3, NumPy, Pillow для измерений. Поиск использует стандартную библиотеку. Запуск из каталога:

```sh
python thickness.py
python dashed.py --seconds 4
python dashed.py --retry 40
python check-variants.py
python build-report.py
```

Поиск ограничен временем; число найденных новых путей может зависеть от машины, сохранённые положительные свидетели проверяются без поиска. Это исследование предложенных конструкций, не восстановление программы автора заставки.
