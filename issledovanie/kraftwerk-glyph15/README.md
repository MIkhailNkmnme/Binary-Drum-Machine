# Глифы Kraftwerk · первые 15 секунд

ИСС-107 · 14 ноября 2026 · v0.001. [Исследование](https://1001100.online/issledovanie/kraftwerk-glyph15/).

Источник: [Kraftwerk live 2025 Coachella soundboard](https://www.youtube.com/watch?v=72x7kbeeGwQ), канал Hotel Mario. Анализируется заставка ролика. Авторская программа анимации не получена и не установлена.

Сохранены 446 снимков области видео при воспроизведении на скорости 0,25, с временем до/после захвата. Исходный файл видео не скачан. Максимальная ширина временного интервала снимка 0,061611 с; максимальный промежуток между такими интервалами 0,029308 с. Почти чёрные и переходные кадры сохранены отдельно от устойчивых схем в данных.

- 15 устойчивых наборов по четыре места; 45 разных клеточных графов на сетке 8×12.
- Все четыре места меняются примерно раз в секунду. Оценка шага 1,002259 с относится к меткам снимков, не к исходным PTS.
- 40 из 45 форм точно совпадают с графами прежнего разбора после нормализации сетки. Это сравнение реконструкций, а не доказательство происхождения исходных анимаций.
- Одним штрихом без повторения ребра рисуются 13 форм: 7 замкнутых и 6 открытых. 9 форм несвязны, 23 связны, но имеют более двух нечётных вершин.
- Полный набор строк 3 и 12 повторяется. Из шести пар с лагом 9 совпадает только одна: глобальный период 9 этим рядом опровергается.
- В 51 из 56 переходов разность рёбер имеет нечётные вершины. Следовательно, обновление только XOR полных замкнутых квадратов не объясняет весь ряд. Само применение XOR для сравнения кадров не является предсказательной моделью.

## Метод и проверки

`analyze.py` измеряет нормированную темноту середин клеточных рёбер. `analysis.json` содержит все наблюдения, уверенность, графы и сравнение со старым набором. `validation.json` проверяет 15 опорных кадров при пяти смещениях сетки и пяти порогах: 375 сочетаний сохраняют рёбра. `check-independent.py` независимо проверяет связность, нечётные степени, квадраты, 56 разностей и хеши 446 снимков. Графовая модель считает пересечения общими узлами и включает внутренние перемычки.

`atlas.svg` / `atlas.png`: 15 строк по четыре глифа; оранжевым отмечены добавленные рёбра. На HTML-странице исчезнувшие рёбра дополнительно показаны синим пунктиром. G-номера идентифицируют одинаковые графы. Числа C/odd/squares в автономном атласе означают связные компоненты, нечётные вершины и единичные квадратные циклы.

Немой `source-excerpt-silent.mp4` длится 15 с и собран из снимков по ближайшим временным серединам. Ошибка сопоставления до 0,024984 с; полный покадровый реестр в `excerpt-provenance.json`. Это не прямой оригинальный фрагмент. В `glyph15-study.zip` только 15 опорных кадров и файлы просмотра; все 446 снимков доступны в `captures/` репозитория.

## Повторение

Нужны Python 3, Pillow, NumPy; FFmpeg и ffprobe для MP4. Анализ использует прежний `../kraftwerk-glyph22/curve-analysis/graphs.json` для сопоставления.

```sh
python analyze.py
python check-independent.py
python build-excerpt.py
python build-page.py
```

`prepare-captures.py RAW_DIR` нужен только для повторного импорта первоначальных полноэкранных снимков. RAW_DIR не публикуется: публичные PNG содержат только область ролика. Все полезные промежуточные значения выделения сохранены в `analysis.json`; реконструкция не исправляет граф ради эйлеровости.
