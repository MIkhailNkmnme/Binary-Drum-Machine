# Русская печатная версия главы 2

Результат: `../chapter-2-ru-print.pdf` — 67 листов A4, 13 783 317 байт. Основной текст 10,7 pt, интерлиньяж 14,6 pt; код 8,2 pt; боковые поля 15 мм. Исходные номера страниц стоят в колонтитулах. Глава охватывает страницы 23–50, примечания — 865–882.

## Что сохранено

- Все 349 блоков подготовленного русского перевода из трёх JSON, а также заголовки. Тексты не сокращались. Точные входные снимки лежат в `translations/`.
- Все иллюстрации в пределах главы и примечаний: 66 вырезок, включая составные панели. Это число вырезок, а не число отдельных диаграмм внутри панелей.
- Полные изображения эволюции со страниц 29–30 и 32–38, в том числе шесть страниц 33–38 без основного текста.
- Все 16 орнаментов страницы 43 с русскими подписями, рисунки к программным примерам, отображения канторова множества, обобщения правила 90, побитовые функции и поверхности, временные графики, схемы орнаментов и верёвок, график публикаций, оба рисунка к коду 10.
- Математические записи, числовые метки осей и программные идентификаторы. Программный код взят из перевода, не исполнялся. Чужие программы и модели не использовались для восстановления рисунков.

## Что исключено и изменено

Английские страницы целиком, английские абзацы, исходные английские подписи и повторные английские колонтитулы не перенесены. Вместо них набран русский перевод. Все рисунки вырезаны непосредственно из пользовательского PDF, включая векторные схемы; они не перерисованы по алгоритмам из книги.

Внутри рисунков переведена 21 метка: 15 `step` → «шаг», 6 `rule` → «правило». Подписи 16 орнаментов заново набраны из русского JSON. Числа, названия функций и переменные внутри рисунков сохранены. Крошечный служебный текст `marker`, обнаруженный в области рисунка страницы 29, удалён; в карту занесена точная операция.

Для чёрно-белой печати все вырезки растрированы в оттенках серого с разрешением 360 dpi. Цветовые оттенки трёхмерных побитовых поверхностей и верёвок преобразованы в серые; геометрия сохранена. Изображения с низким исходным разрешением остались столь же детальными, как в предоставленном PDF: увеличение не создаёт отсутствующих деталей.

У каждой исходной страницы отдельный раздел. Длинные страницы примечаний продолжаются на следующих листах. Ради читаемости некоторые подписи и рисунки перемещены в непосредственную близость к описывающему их тексту. Нумерация ссылок в авторском тексте относится к исходной книге, а не к новым 67 листам.

## Воспроизведение

Нужны Python 3, `pymupdf`, `reportlab`, шрифты Arial, Consolas и Segoe UI Symbol. Сборщик не использует сеть. В стандартном расположении файла пользователя:

```powershell
python .\build_print.py
```

Для переноса в другое место:

```powershell
python .\build_print.py --source 'D:\source\nks-ch2.pdf' --translations '.\translations' --output 'D:\output\Глава 2.pdf' --fonts 'C:\Windows\Fonts'
```

Фактически использован Python:
`C:\Users\Администратор\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe`.

`build_print.py` содержит прямоугольники всех вырезок, порядок вставки рисунков и параметры набора. `figure-manifest.json` содержит хеш исходного PDF, хеши трёх JSON, хеш итогового PDF, точные координаты вырезок, переведённые метки, пути изображений и соответствие всех новых листов исходным страницам. Папка `figures/` содержит готовые вырезки.

## Публичная копия
