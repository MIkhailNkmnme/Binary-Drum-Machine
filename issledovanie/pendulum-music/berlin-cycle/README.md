# Берлинский цикл · Зеркалиус

Первый собственный эскиз по направлению, предложенному пользователем после KOBTRAX — Elektronische Träume. Основание — предоставленное авторское описание с YouTube: воображаемая запись 1975 года, развивающиеся последовательности, аналоговая нестабильность и шум ленты. Фонограмма KOBTRAX не использовалась; точное сходство на слух не оценивалось.

[Живой опыт](https://1001100.online/mayatnik/Zerkalius-mayatnik-synthesis.html?synthExample=berlin-cycle&gpu=0): включить «Звук», затем «Пуск». Исходный дуэт 129 × 64, якорь 64, pend/pendR, сдвиг фазы B на 11, XOR со следом 6 кадров. Именованная ссылка открывает отдельный воспроизводимый опыт.

Ряды из восьми и семи нот и четыре медленные гармонические области заданы композицией. Второй ряд появляется с пятого такта, отдыхает в тактах 17–20, возвращается в 21-м и редеет в конце. Плотность крайних полос поля влияет на завершающие ноты рядов, общая плотность — на тембр, разница половин — на панораму. Высота слегка дрейфует; в протяжённом голосе есть тихий синтезированный шум.

Эскиз: 96 BPM, 32 такта (80 секунд музыкального времени плюс затухание последних нот). MP3/WAV содержат авторские тембры; MIDI передаёт нотные события, но не PCM-особенности. `score.json` хранит исходный снимок, события, параметры и хеши источников/файлов.

Сборка из корня репозитория:

```sh
node issledovanie/pendulum-music/berlin-cycle/build.cjs
```

Нужны Node и FFmpeg (PATH либо FFMPEG_PATH). Модули полей/событий/голосов общие с живым опытом. Это производство эскиза; автотесты, синтаксические проверки, браузерная и слуховая приёмка не выполнялись. Просмотр и прослушивание — пользователем.
