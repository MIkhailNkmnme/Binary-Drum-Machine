# Маятниковые композиции: данные и проверка

СИН-005 · 13 ноября 2026. Статья0.001, общий индекс Исследований0.113. Ядро Синтеза0.006 и выпущенные музыкальные оригиналы не изменены.

Партитура состоит из заданной гармонии/мотива/ритма и вариаций, вычисляемых по A/B/result. Пустой контроль заменяет все три поля значением−1 при тех же настройках. Числа в статье получены `music-provenance-check.cjs`; категории различий пересекаются.

Из корня клона:

```powershell
node issledovanie/pendulum-music/music-provenance-check.cjs
```

Сравнение событий работает по опубликованным параметрам. Чтобы дополнительно сравнить WAV/MIDI побайтно, вторым аргументом после пути репозитория передайте распакованный альбом с исходными WAV/MIDI и construction-parameters.json. Отсутствующие файлы отмечаются `null`, а не успешной проверкой. Необязательный третий аргумент после этих путей задаёт новый JSON-отчёт; сохранённый результат публикации по умолчанию не перезаписывается.

Проверено при создании выпуска:

- Пересчитанные оригинальные WAV и MIDI совпали побайтно для двух композиций. Настройки MP3 подтверждены побайтовым повторным кодированием оригиналов. Два пустых контроля используют прежний уровень0,62, тот же лимитер и кодек, без отдельной нормализации.
- Видео H.264,1920×1080,30fps CFR; AAC,стерео,44100Гц; обе дорожки начинаются с0. MP4 имеет faststart. Последняя картинка камерной версии длится72,6с, звук72,571429с: округление меньше одного кадра.
- Проверены12 декодированных кадров, включая середину и коду. Средняя абсолютная ошибка цвета после сжатия1,63–3,65 из255; выбран правильный шаг. Число звуковых отсчётов совпало с WAV, SNR AAC относительно WAV35,41/43,05dB. Подробности и хеши: `../../mayatnik/synthesis-album/video-sync.json`.
- Все новые локальные ссылки, уникальныеID новой страницы,2video+4audio, синтаксисJS и совпадение хешей перенесённыхMP4 проверены.
