Маятник v1.023

Маятник на 64 строках

«Хорр» строит исходное поле. «Аниматрица» меняет его по кадрам. «Продолжение» добавляет биты от точки встречи. На снимках показаны реальные кадры Маятника.

ХоррАниматрицаПродолжение и 180°

Хорр

Меню задаёт высоту, число вершин и способ построения поля. Для примеров использовано 64 строки и остановленный кадр 48 обычного Маятника. Открыть пример на 64 строки.

Размер

Откройте Хорр → Размер. В поле под готовыми размерами введите 64 и нажмите Задать или Enter. В обычном Маятнике две половины N/3 | 4N выбирают диапазон вершин. На 64 строках это 23 и 256 вершин соответственно. Повторное нажатие выбранной половины возвращает N, то есть 64 вершины. Ниже расположен отдельный лимит строк своего исходника. Значение 0 берёт все строки библиотеки.

Построение

ЛевПрав ставит вершины по порядку 0, −1, +1, −2, +2. ПравЛев ставит их в порядке 0, +1, −1, +2, −2. Построить считает все вершины сразу. Прогон строк раскрывает рассчитанное поле сверху вниз. Рамка шага отмечает биты последней рассчитанной строки. Продолжать снимает предел 2N−1 для режима Конусы.

Поля

Маятник возвращает обычное построение. Своя последовательность берёт строки из библиотеки как исходник. Своя решётка меняет ход вершин с одного столбца на два. Инверсия сверху заполняет внутренние пустые клетки конуса инверсией бита над ними. Пустоты 0 открывает способы заполнения нулевого кадра при совместимом источнике.

Ход XOR переключает вершины и пересчитывает конус. С 0 начинает с исходного конуса, С −1 с пустого поля, а Перескок 0 пропускает нулевую позицию. Можно вести одну сторону, две сразу или две по очереди. Для совпадения двух вершин в нуле варианты 0 ×1 и 0 ×2 переключают её один и два раза соответственно.

Конусы применяют XOR внутри нового конуса. Поле применяет XOR ко всему полю. Обе стороны обрабатывает зеркальную пару вершин за ход. При 64 строках у этих трёх полей ширина 127 клеток. Рандом строит тестовый квадрат, Ковёр выводит ковёр Серпинского.

Ромбо

Ромб включает сборку исходных участков вокруг горизонтальной оси. Её строку можно задать числом или сдвигать стрелками. Поворот меняет угол с шагом 45° в положениях, совместимых с точной сеткой. Сборка выбирает схему. Убрать дубль убирает повторную колонку на центральном шве совместимых схем. Детали открывают редактор частей, Готовые возвращает выбор готовой сборки, Схемы 10 показывает схемы.

Нижние

Подменю накладывает друг на друга результаты построений Конусы, Обе стороны и Поле. Можно взять любую из трёх пар либо все три результата. Верхняя кнопка переключает XOR и AND. Прямо и Зеркально выбирают ориентацию правого источника «Поле».

Прогон

Сборка запускает прогон тестового построения. Повторное нажатие останавливает. Соседняя кнопка переключает построение по строкам и кадрам. Счёт показывает числа единиц, нулей и пустых клеток. Запомнить сохраняет тестовый кадр, С кадра восстанавливает сохранённый кадр для прогона. Под шестью разделами самого меню Всё поле очищает и сбрасывает текущее поле, Остановить всё останавливает транспорт.

Аниматрица

В меню Аниматрица выберите алгоритм и нажмите Пуск. Выбор алгоритма готовит кадр 0 и оставляет плеер на паузе. Чтобы повторить примеры ниже, задайте 64 в Хорр → Размер. У отражения «Копии XOR» исходник остаётся 64 строки, а расчётное поле продолжается за его нижний край.

Глубина задаёт число строк конуса вместе с вершиной. У ромба и качания значение применяется в обе стороны. Смена окрашивает фон при изменении бита, синим для единицы и красным для нуля. Уже окрашенный синий или красный фон при следующей смене возвращается к обычному цвету. Excel применяет правило окраски ко всем посещённым клеткам, в том числе там, где бит сохранился.

Исходник, цвета и циклы

  • Весь кадр берёт текущее поле целиком. Область берёт выделенный прямоугольник. Сначала выделите клетки, затем нажмите кнопку. В построчном расчёте и отражениях используется всё поле.
  • С нуля создаёт чистый исходник для выбранного алгоритма. Пример открывает учебный исходник на 32 строки. После этого можно снова задать 64. Кадр 0 возвращает сохранённый исходник.
  • Исходные сохраняет исходную окраску. Биты показывает цвета нуля и единицы. Для Excel-режимов применяются их собственные правила.
  • Число выполняет от 1 до 64 циклов. ∞ продолжает расчёт до паузы. Повтор ищет точное совпадение состояния, определяет начало и период и останавливает плеер. У «Столкновения» один кадр и свой останов.

Что проверено на 64 строках

В Chrome прошли 49 действий и 25 запусков плеера. У «Столкновения» первый кадр появился через 521 мс. У «ИнтерXOR» на чистом исходнике кадр 3 может выглядеть пустым в «Обзоре». На масштабе 1:1 в нём видны все 2084 клетки. На снимке «ИнтерXOR» использована выделенная область.

Продолжение

Откройте обычный Маятник на 64 строках, остановитесь на кадре 49 и включите «Продолжение». От точки встречи пойдут XOR-конусы с рядами 1, 11, 101, 1111. Точка остаётся осью построения. Её положение меняет то, какие биты пересекутся с исходным полем.

Направления и край

«Вниз», «Вверх», «Влево» и «Вправо» выбираются независимо. «Все» включает или снимает все четыре галочки. «Нижний край» относится к направлению «Вниз».

  • Прямо продолжает конус ниже края исходных строк.
  • Зеркало добавляет отражение вверх от последней строки.
  • Через низ переносит вышедший вниз бит наверх в тот же столбец.

Наложение и цвета

В таблице A — бит Маятника, B — бит продолжения. Формула применяется там, где есть оба бита. Без A рисуется B в обычном цвете бита. Без B остаётся исходное поле. «Прозрачно» смешивает цвета в месте пересечения. «Пересечение» добавляет золотистую подсветку на всех общих клетках, в том числе когда результат равен 0.

Оси, 180° и экспорт

  • Скрыть оси убирает оси и точку с картинки. После выключения и включения «Продолжения» оси снова видны.
  • Вид → 180° даёт полное исходное поле сверху и повёрнутую копию снизу. Наложение тоже поворачивается. Верхняя точка управляет обоими рисунками. Отдельная команда «Решётки» сохраняет прежнее деление по чётности.
  • Прямоугольник берёт текущий результат как исходник фиксированного размера. «Обычное поле» возвращает обычное построение.
  • 4 GIF записывает по файлу на каждое направление с текущего кадра. GIF квадраты записывает полный диапазон кадров и берёт квадрат вокруг точки оси. На 64 строках стороны квадратов — 16, 32, 64 и 128. После GIF можно собрать видео с музыкой из битов.

Как сочетать режимы

КомбинацияЧто получается
Хорр + АниматрицаХорр строит исходник. Аниматрица принимает весь кадр, выделенную область или свой чистый исходник. Размер исходника и высота отображаемого результата могут различаться.
Аниматрица + 180°Два представления одного кадра. Правило расчёта и номер кадра общие. «Встык» и «Встык 2×2» сохраняют свою сетку.
Продолжение + 180°Операция применяется к рисунку вокруг точки встречи, нижнее наложение повторяет верхнее с поворотом.
Аниматрица + ПродолжениеПодвижная ось Аниматрицы задаётся её алгоритмом. Продолжение строится от точки встречи обычного Маятника. Для него вернитесь к обычному построению.
Продолжение + ВстыкДля продолжения от точки встречи и его экспорта используется обычная плоская сетка. Сам режим 180° поддерживает Встык.
Продолжение + 4 GIF / GIF квадратыДля экспорта откройте плоское поле Маятника. 180°, Встык и Ромбо отключаются вручную перед записью.

Полную копию 180° проверили в «Битах», «Покрытиях», «Цифрах», «RGB-соседях», шести ромбических представлениях и двух видах «Встык». Для режима «Ромбы · всё поле» и больших полей WebGPU эта копия пока недоступна.
