# Голос из буков и цифр: SAPI → робот → вокодер

Черновик · 17 ноября 2026. Всё сделано на этой машине: голоса Windows (SAPI), обработка ffmpeg, вокодер на numpy. **На слух не проверялось** — только измерениями.

## Что получилось

| Что | Файл | Как звучит |
|---|---|---|
| цифры 1–8, робот | `count-ru.mp3` | по цифре на такт, металлический голос |
| петля + цифры | `loop-ru.mp3` | счёт поверх трека |
| буквы «ZERKALIUS» | `letters-zerkalius.mp3` | по букве на восьмую, у каждой своя высота |
| петля + буквы, музыка приседает | `loop-letters-zerkalius-ducked.mp3` | голос впереди, музыка уходит на −4,7 дБ |
| вокодер | `vocoder-ru.mp3` | голос управляет гармоникой трека |

## Расчеловечивание голоса

| Шаг | Что делает | Значение |
|---|---|---|
| `asetrate` + `atempo` | понижает голос, растягивает форманты | ×0,72 (≈ −6 полутонов) |
| кольцевая модуляция | металлический призвук — главный признак робота | синус 58 Гц, микс 0,42 |
| `acrusher` | огрубляет до цифры | 6 бит |
| `highpass` + `lowpass` | оставляет вокодерную полосу | 220–4200 Гц |

## Каждая буква — своя нота

Буквы сортируются, и номер задаёт ступень до-минора. Для «ZERKALIUS»:

| Буква | Ступень | Сдвиг |
|---|---|---|
| A | 0 | −3 |
| E | 2 | −1 |
| I | 3 | 0 |
| K | 5 | +2 |
| L | 7 | +4 |
| R | 8 | +5 |
| S | 10 | +7 |
| U | 0 | −3 |
| Z | 2 | −1 |

Слово произносится по букве на восьмую (0,48 с), после слова — такт паузы. В петлю 46,08 с помещается 7 полных проговариваний.

## Вокодер

Канальный вокодер: короткие спектры несущей (петля) и модулятора (счёт), 24 полосы по логарифму 120–7000 Гц; в каждой полосе огибающая голоса задаёт усиление несущей, обратное преобразование собирает «речь» тембром трека. Это архитектура Крафтверка: не голос, а синтезатор, которому показали, как шевелить губами.

## Проверки

- Петля остаётся петлёй с голосом: минимум RMS в окне стыка 0,107 — как без голоса.
- «ZERKALIUS»: стемма 49,92 с, 26 % активных 20-мс окон, пик 0,586; добавка к петле RMS 0,010.
- С приседанием: пик 0,653, RMS 0,119, приседание до 0,42 (−4,7 дБ).
- Вокодер: RMS 0,013–0,015, пик 0,4; спектр ограничен 7 кГц, как задано полосами.

## Как повторить

```powershell
python letters.py        # буквы: синтез, обработка, петля
python duck.py           # версия с приседанием музыки
python vocoder.py        # вокодер поверх петли
```

Нужны Windows SAPI (PowerShell 5.1), ffmpeg в PATH и numpy. Скрипты читают петлю из `../../music` — путь правится в первой строке констант.

## Ограничения

- **Не прослушано.** Вокодер выглядит на спектрограмме как короткие вспышки на каждом такте, а не как тянущаяся речь: возможно, слишком «кликает». Это гипотеза, а не вывод.
- **Немецкого счёта нет**: в системе только ru-RU и en-US голоса. У Крафтверка считается «eins, zwei, drei…» — для этого нужен espeak-ng.
- Буквы читаются как названия букв («эй», «зэд»); как именно SAPI произносит одиночную букву, зависит от голоса.
- Высота голоса подогнана под до-минор, но не под конкретный аккорд в каждый момент — на слух может местами спорить с подложкой.
