# Голос: только синтез

Черновик · 17 ноября 2026. Правило проекта: в Зеркалиусе только искусственный звук — никаких
записанных голосов, никаких аналоговых сэмплов.

## Что здесь

| Файл | Что это |
|---|---|
| `numbers-67-synth.mp3` | «Numbers» 1:57, 67 BPM, счёт цифрами на **полностью синтетическом** голосе |
| `synth-digit-spectrum.png` | спектр одной синтетической цифры: гармоники возбудителя и шумовые участки согласных |
| `numbers-sketch.cjs` | музыкальная подложка без голоса (32 такта, 90/67 BPM, бас из битов) |

Синтезатор и миксер лежат в `tools/voice/`:
`formant_voice.py` — импульсный возбудитель и три резонатора, форманты гласных в герцах,
согласные шумом и импульсами; `mix_synth_numbers.py` — раскладка цифр по пульсу и приседание музыки.

## Что удалено и почему

18 ноября 2026 из папки bit-voice убраны голосовые материалы на Windows SAPI: цифры, буквы,
вокодер и треки с ними. Причина: **для использованных системных голосов не подтверждено отсутствие
человеческих записей в исходной технологии**. Само название SAPI обозначает интерфейс,
а не доказывает устройство конкретного голоса. Для правила проекта такого происхождения недостаточно.

Удалённые файлы остаются в истории git (коммиты до удаления `60c301c81`), но в актуальном состоянии их нет:
`count-ru/en`, `letters-zerkalius`, `loop-letters-zerkalius-ducked`, `loop-ru-count`, `numbers-67`,
`numbers-sketch.mp3`, `vocoder-ru` и скрипты `make_voice.py`, `letters.py`, `duck.py`, `vocoder.py`,
`mix_numbers.py`, `mix_voice.py`.

## Как устроен синтетический голос

1. Возбудитель — последовательность коротких импульсов с падающей частотой (112 → 96 Гц):
   голосовая щель как математическая функция, а не запись.
2. Три последовательных резонатора задают форманты: для «а» это 700 / 1300 / 2500 Гц,
   для «и» — 300 / 2200 / 3000 Гц.
3. Согласные — шумовые участки (с, ш, ф), импульсы (п, т, к) и носовые/дрожащие (н, м, р).
4. Слово собирается из фонем: «восемь» = в-о-с-и-м-ь, мягкий знак не звучит.

## Ограничения

- Разборчивость процедурного голоса требует слуховой оценки; происхождение звука
  и узнаваемость слов — разные критерии.
- Буквы «ZERKALIUS» уже перенесены на формантный синтез, см. следующий раздел.
- В актуальном блоге старые ссылки на SAPI-видео сняты; для Numbers размещена новая
  ссылка `RmrFiFyqXPA`. Состояние старых роликов на самом YouTube этим не подтверждается.

## Буквы на формантном синтезе

loop-letters-synth.mp3 — 46,08 с, петля 125 BPM. Слово ZERKALIUS проговаривается по буквам:
у каждой своя высота (A −3, E −1, I 0, K +2, L +4, R +5, S +7, U −3, Z −1), буква на четверть,
после слова такт паузы, в петлю помещается 7,6 проговариваний.

Пик 0,727, RMS 0,127. Собирается так:

`powershell
python tools/voice/build_letters.py ZERKALIUS music/zerkalius-loop.wav loop-letters-synth.wav
`

Названия букв — русские (зэт, е, эр, ка, а, эль, и, у, эс), потому что формантный синтезатор
работает с русскими фонемами. Спектр — letters-synth-spectrum.png.

**Ограничение:** разборчивость оценивает пользователь. Источник речи —
импульсный возбудитель и резонаторы, без записанного голоса.
