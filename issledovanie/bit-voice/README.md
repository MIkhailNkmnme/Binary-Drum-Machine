## Расчеловечивание голоса

| Шаг | Что делает | Значение |
|---|---|---|
| `asetrate` + `atempo` | понижает голос, растягивает форманты | ×0,72 (≈ −6 полутонов) |
| кольцевая модуляция | металлический призвук — главный признак робота | синус 58 Гц, микс 0,42 |
| `acrusher` | огрубляет до цифры | 6 бит |
| `highpass` + `lowpass` | оставляет вокодерную полосу | 220–4200 Гц |

## Каждая буква — своя нота

Буквы сортируются, и номер задаёт ступень до-минора. Для «ZERKALIUS»:

| Буква | Ступень | Сдвиг |
|---|---|---|
| A | 0 | −3 |
| E | 2 | −1 |
| I | 3 | 0 |
| K | 5 | +2 |
| L | 7 | +4 |
| R | 8 | +5 |
| S | 10 | +7 |
| U | 0 | −3 |
| Z | 2 | −1 |

Слово произносится по букве на восьмую (0,48 с), после слова — такт паузы. В петлю 46,08 с помещается 7 полных проговариваний.

## Вокодер

Канальный вокодер: короткие спектры несущей (петля) и модулятора (счёт), 24 полосы по логарифму 120–7000 Гц; в каждой полосе огибающая голоса задаёт усиление несущей, обратное преобразование собирает «речь» тембром трека. Это архитектура Крафтверка: не голос, а синтезатор, которому показали, как шевелить губами.

## Проверки

- Петля остаётся петлёй с голосом: минимум RMS в окне стыка 0,107 — как без голоса.
- «ZERKALIUS»: стемма 49,92 с, 26 % активных 20-мс окон, пик 0,586; добавка к петле RMS 0,010.
- С приседанием: пик 0,653, RMS 0,119, приседание до 0,42 (−4,7 дБ).
- Вокодер: RMS 0,013–0,015, пик 0,4; спектр ограничен 7 кГц, как задано полосами.

## Как повторить

```powershell
python letters.py        # буквы: синтез, обработка, петля
python duck.py           # версия с приседанием музыки
python vocoder.py        # вокодер поверх петли
```

Нужны Windows SAPI (PowerShell 5.1), ffmpeg в PATH и numpy. Скрипты читают петлю из `../../music` — путь правится в первой строке констант.

## Ограничения

- **Не прослушано.** Вокодер выглядит на спектрограмме как короткие вспышки на каждом такте, а не как тянущаяся речь: возможно, слишком «кликает». Это гипотеза, а не вывод.
- **Немецкого счёта нет**: в системе только ru-RU и en-US голоса. У Крафтверка считается «eins, zwei, drei…» — для этого нужен espeak-ng.
- Буквы читаются как названия букв («эй», «зэд»); как именно SAPI произносит одиночную букву, зависит от голоса.
- Высота голоса подогнана под до-минор, но не под конкретный аккорд в каждый момент — на слух может местами спорить с подложкой.
## Набросок «Numbers» (90 BPM)

`numbers-sketch.mp3` — 1:27, 32 такта, 90 BPM: бочка на каждой доле, снейр на 2 и 4, хэт на слабой восьмой, бас-остинато из битов по рисунку 0 3 5 3 0 3 7 5, холодные аккорды двумя нотами через такт и счёт цифрами роботом — по цифре на такт, 1→8 четыре круга, музыка приседает под голосом на −4,7 дБ.

Собирается двумя шагами:

```powershell
node numbers-sketch.cjs .        # музыка без голоса -> numbers-bed.wav
python mix_numbers.py            # счёт цифрами -> numbers-sketch.wav
```

Пик 0,556, RMS 0,093, 33 цифры. Спектрограмма — `numbers-spectrum.png`.
Это отклик на референс Karl Bartos «Numbers»: его разбор — в `../bartos-numbers/`.

## Версия 67 BPM — темп референса

`numbers-67.mp3` — 1:57, 32 такта, 67 BPM: тот же рисунок, но счёт идёт не по такту,
а по пульсу 0,896 с — как в разборе Bartos. Цифра через пульс (шаг 2), 66 цифр, приседание


Пик 0,559, RMS 0,077 при подложке 0,569 / 0,085 — музыка дышит.

### Найденный по дороге баг движка

На медленном темпе бочка рендерилась в полную тишину. Причина в `mayatnik-synthesis-music.js`:
в `renderVoice` знаменатель огибающей `length - duration` уходил в минус, когда нота в секундах
дольше выбранной длины голоса, и `release` обнулял сигнал целиком. Исправлено отдельным
условием (`releaseSpan > 0`, иначе огибающая 1 и только 9-мс затухание), тест —
`mayatnik/mayatnik-synthesis-tempo.test.cjs`. На 120 и 100 BPM звук побайтово прежний;
на 90 изменился именно заглушённый ранее хэт.


## Голоса: два вида, и это важно

Правило проекта: только искусственный звук, никаких записанных аналогов. Здесь два разных голоса,
и путать их нельзя.

| Вид | Что внутри | Файлы |
|---|---|---|
| **SAPI (Windows)** | голоса Microsoft Irina/Zira — это **синтез из записей человека**: в них есть фрагменты настоящей речи | `count-ru.mp3`, `count-en.mp3`, `letters-zerkalius.mp3`, `loop-ru-count.mp3`, `loop-letters-zerkalius-ducked.mp3`, `numbers-67.mp3` |
| **Формантный (чистая математика)** | импульсный возбудитель + три резонатора, ни одного сэмпла | `numbers-67-synth.mp3`, `synth-digit-spectrum.png` |

Формантный голос: `tools/voice/formant_voice.py` — цифры как последовательности фонем, форманты
гласных в герцах, согласные шумом и импульсами. Проверено на спектре: видны гармоники возбудителя
и шумовые участки согласных, человеческих записей нет.

`numbers-67-synth.mp3` — та же подложка 67 BPM, но счёт синтетический: 66 цифр через пульс,
пик 0,688, RMS 0,083.

**Ограничение:** SAPI-версии звучат разборчивее, потому что в них настоящая речь. Формантная
пока грубее и требует доводки — но она единственная, что соответствует правилу.
