## Чего нет

- Слова не распознавались: в системе нет распознавания речи, на слух не проверялось.
  Партитура описывает ритм, а не текст; что читаются немецкие числа — допущение из оригинала.
- «Голосовость» — эвристика по полосе, точность не измерена.
- Темп 67 BPM — это пульс счёта; метрика может быть вдвое плотнее (134).
