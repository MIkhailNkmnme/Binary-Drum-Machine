## Звук и происхождение

Все звуки — собственный математический синтез: синусоидальные генераторы, фильтры, шум, ручные фонемные рецепты. Записи, готовые голоса, обученные речевые модели, сторонние сэмплы и мелодии не использованы. Папка provenance хранит последовательность сборки прежнего принятого звука; её скрипты являются историческими, пути/имена соответствуют старым промежуточным версиям. Для новой сборки используются скрипты в корне этого пакета.

Первые 180 секунд в мастер-WAV перенесены из принятого v9 без изменения PCM. Дальше продолжается тот же музыкальный рисунок; переход из прежней версии занимает 0,25 секунды. Новый французский, итальянский, испанский и японский синтезированы из Глсъ v0.033, коммит 7325779241728a416ad78a9fa2f6a83bd3bf4e7d. Французское un имеет удлинённую гласную; русский ади́ин сохранён из принятой версии.

Нормировка каждого нового голосового фрагмента: min(0.043/RMS, 0.19/peak), затем **0.375 × 10^(−3/20) = 0.26547967**. Это согласованная громкость v9. Дождь: **0.5 от v4**, базовый RMS 0.00225 до огибающей; во время речи коэффициент 0.45. Общей нормализации микса нет. Файл seven-language-v10-manifest.json содержит фактические длительности и коэффициенты.

## Изображение

Исходный сохранённый кадр Маятника 126; реальные чётные состояния 126…1564 с шагом 2. Каждое удерживается 0,625 секунды. Узор рендерится из данных 2052×1024 в фигуру 1400×699, а не увеличивается из старого видео. Дискретное покачивание и два часовых маятника сохранены. Субтитры японского используют Yu Gothic.

## Пересборка

Полный ZIP в выпуске содержит этот код, снимки собственных синтезаторов, исходный файл Маятника и необходимые собственные WAV. Требуются Node.js, Python с NumPy/Pillow, FFmpeg, Windows Segoe UI и Yu Gothic. Из распакованной папки:

```text
node export_even_scene_v10.cjs
python render_symbiosis_v10.py
python assemble_seven_v10.py
python encode_v10.py
```

Сохранённые WAV четырёх новых языков уже включены. Для их повторного синтеза перенесите voice-v10-*.wav и extra-voice-timeline-v10.json в резервную папку, затем запустите node build_extra_voices_v10.cjs. Генератор защищает существующие фрагменты от перезаписи. Предыдущие 336 PNG можно опционально положить в symbiosis-fullhd-v3-render для ускорения; без них все 720 состояний рисуются заново.

Чтение исходников выполнено координатором и внутренним исполнителем. Автотесты, браузерная и слуховая приёмка не выполнялись; приёмка пользователем. Технические параметры готового медиа записаны в delivery.json.
