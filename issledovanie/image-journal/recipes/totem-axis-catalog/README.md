# Покадровый сбор фигур центральной оси

В исходном GIF 194 кадра размером 537 × 413 и длительностью 183,61 секунды.
193 кадра различаются по пикселям. В 11 участках из [схемы вырезок](sources.json)
найдено 1119 непустых вариантов. Вариант — уникальная комбинация RGB-пикселей
в заданном диапазоне строк. Границу унаследовали из разметки последнего кадра.
Форма может занимать несколько участков. Для её выделения используйте полный PNG
или соедините нужные участки по записанным координатам.

[Исходный GIF](https://media.1001100.online/image-journal-2026-11-21/central-axis-templates.gif) ·
[Покадровый индекс](frame-index.json)

## Как читать индекс

- `frames` перечисляет все кадры в исходном порядке. Нумерация с нуля. `start_ms` и
  `duration_ms` сохраняют время показа GIF. `same_as` указывает на первый кадр с теми же
  пикселями. `bands` содержит по одному значению для каждого участка сверху вниз.
- `bands` хранит диапазоны строк и варианты. Начальная строка включена, конечная
  исключена. Номер варианта указан в записи соответствующего кадра. Пустой
  участок обозначен `null`. `left` — столбец, где начинается PNG вырезки. `first_frame`
  — индекс первого кадра с этим вариантом.
- SHA-256 кадра вычислен по декодированным RGB-пикселям. Для вырезки хеш рассчитан
  по всей ширине участка, включая боковой чёрный фон. Сохранённые PNG вырезок
  обрезаны по ширине и вставляются обратно с позиции `left`.
- Индекс относится к этой записи. Другие настройки и записи Маятника образуют
  отдельные наборы.

## Как сохранить все PNG и CSV

Из папки рецепта запустите команду с Python и Pillow. Путь указывает новую папку.
При повторном запуске задайте новое имя выходной папки.

```powershell
python extract-frames.py "E:\GD\_pzl\Zerkulis\обои Зеркалиус\Покадровый сбор"
```

Оригинал берётся из `issledovanie/central-axis-film/central-axis-source.gif`.
При запуске отдельно от репозитория передайте путь к тому же GIF через `--source`
и положите `sources.json` рядом со сборщиком. Сборщик сверит исходник по SHA-256.

Целые кадры лежат в `frames/`, непустые варианты в `bands/01/`–`bands/11/`.
Таблица `frame-index.csv` открывается в Excel. Для ручной сборки кадра используйте
время показа и номера PNG из JSON.
